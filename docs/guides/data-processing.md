# 历史采集与数据处理

“数据处理”在现有深色琥珀工作区内提供“单设备采集 / 批量采集”两个页签。此流程离线读取已经保存的数据，不连接仪器。

## 查找和处理

自动搜索设置中的数据目录、运行目录下的旧默认 `data`，以及此前添加的目录。点击“添加数据目录”导入其他历史文件夹；“刷新”重新扫描。重叠目录按实际路径去重，结果文件夹不会再作为原始记录导入。列表按原始采集时间倒序排列，显示开始时间及其时区、参与设备和处理状态，重命名不改变采集时间或身份。

列表按元数据中的采集日期分组，点击日期左侧箭头展开或折叠；刷新及切换分类会保留折叠状态，日期沿用记录自带时区。

每条记录可以“处理数据、移动、移入回收站、重命名、打开文件夹”。“打开文件夹”在文件资源管理器打开整次采集目录，批量记录打开整个批次。点击记录进入详情，单设备直接显示该设备，批量采集通过设备列表选择一台。未处理的设备显示处理入口；后台按设备串行整理和生成 PNG，在列表和详情显示当前设备及进度，可取消。某台设备失败会保留错误说明，并继续处理其他设备。

首版支持以下数据；显示方式根据实际数组和横轴判断，不把文件的 `single_frame` 或 `continuous` 标签当作图形类型。

| 设备 | 查看方式 |
| --- | --- |
| JW8105 | 全部通道的完整功率时间曲线，可切换 W / dBm 显示；保存仍为原始单位 |
| M300 | 各通道时间曲线，按温度、电压、电阻及单位分组；温度同时提供末尾 30 min 峰峰值 |
| K+K FXE / FXE2 | 各通道完整频率时间曲线 |
| 6362D | 波长—功率曲线，拖动时间线选择光谱帧 |
| DHO924、RTM3004 | 各通道原始时轴波形，拖动时间线选择采集帧 |

不执行滤波、FFT 或拟合。温度峰峰值仅为窗口内最大值减最小值，不代表准确度或其他稳定度指标。其他型号明确显示暂不支持，不套用上述设备的解释。

## 曲线查看

可以勾选通道、切换物理量/单位分组、滚轮缩放、拖动平移和“适应全部数据”。光标显示邻近曲线点读数；长记录的全览使用极值包络，光标对应当前显示点，缩放后重新读取该区间。标量图覆盖整次记录，不受实时监测的滑动窗口限制。CSV 和 SQLite 保存全部原始精度数据。

“适应全部数据”依据选中通道的完整数值范围重置横、纵轴，不受此前平移、缩放或显示裁剪影响。曲线使用柔和琥珀、青蓝、浅绿、淡紫等固定通道色，勾选其他通道不会改变颜色。DHO924、RTM3004 记录包含示波器显示元数据时，默认按采集时各通道独立量程和偏移显示，纵轴明确标为“垂直格”，图例标注每格的实际单位；取消“示波器刻度”可查看统一电压坐标。光标和导出的图片始终使用原始物理值，不将格数当作电压。

整帧数据按需随机读取，不重新解析 CSV；拖动期间只保留最新待处理请求，旧读取不会覆盖当前帧。时间线显示实际读回时间、时区、帧号、总帧数和距开始时间，支持上一帧/下一帧。仅一帧时仍显示图形，时间线固定。

优先使用记录中的单调时钟相对秒数，历史数据没有该字段时使用带时区的原始读回时间差。通道各自的时间、单位、配置及缺口保持原样，不补零、不插值、不推断跨设备同步。无时区或回退的历史时间不能作为可靠时间曲线，处理会明确失败；已有单调时钟的记录允许墙上时间回调。W 转 dBm 时，非正功率无法取对数，显示为缺口，不使用任意噪声底替代。

## 论文插图

温度通道列表显示每路峰峰值，悬浮可查看统计起止时间、最小值、最大值及样本数。所有通道共用记录的最后时间作为终点，统计 `[终点 − 1800 s, 终点]`（包含边界）；记录不足 30 min 时使用全部有效数据。某通道在窗口中没有样本显示“—”，单样本为 0，不因缺测而向前扩大窗口。统计来自完整数据，不受曲线抽样、勾选、缩放或平移影响；原始曲线仍覆盖整次记录。历史直接温度按记录值统计，不套用新曲线重新换算。

点击列表的“处理数据”或详情的“处理本次采集”，会自动生成 183 mm、600 dpi PNG，无需另外导出。除已声明逐通道分图的示波器外，同物理量、单位和横轴的全部通道合到一张图：标量绘制完整时间曲线，光谱逐帧生成。DHO924 和 RTM3004 每一帧的每个通道分别生成独立 PNG。后台串行读取和绘图，列表及详情显示阶段和进度，支持取消；只有 PNG 保存到型号目录后，本设备的处理任务才算完成。密集噪声曲线采用分批线段绘制，批次间检查取消，避免长路径绘制阻塞界面。

真实配置变化和采集缺口仍断开曲线，孤立的有效采样显示为圆点。K+K 的设备时间戳和报告文本属于逐帧信息，不再被误当成配置变化；完整原始内容照常保留。图片忠实呈现原始数组，原始帧完全相同时图片也会相同，处理不会制造新的测量数据。

App 中的查看仍采用深色交互曲线。自动 PNG 使用独立的 Nature 风格：白底、Arial 8 pt、0.65 pt 线宽、简洁左/下坐标轴及无装饰网格。坐标轴以英文物理量和单位标注，不把 App 截图当作论文图。

页面不再提供手动导出、尺寸或格式选择。自动图片包含记录中全部通道和帧，界面上的通道勾选、缩放和单位切换不会改变它们。图片只是显示表示，完整数据保留在原始采集文件和内部 CSV/SQLite 缓存中。

包含温度的标量记录另生成 `温度峰峰值.png`：列出通道、单位、最小值、最大值、峰峰值和样本数，标题标明末尾 30 min 的实际时间范围。完整精度统计也保存在内部处理结果中。旧缓存仍可查看，重新处理时升级缓存并生成汇总图。

## 输出与重复处理

图片位于**整次采集文件夹**的 `数据处理` 子目录，按槽位或型号区分；“打开处理目录”直接打开当前设备的图片目录。该目录只展示 PNG 及必要的通道、帧序列文件夹：

```text
采集文件夹/
  原始采集文件或各设备原始文件夹/
  数据处理/
    单通道型号_记录标识/
      功率_dBm.png
    多通道型号_记录标识/
      功率_dBm.png
    连续光谱型号_记录标识/
      帧序列/
        光谱_dBm_000001.png
        光谱_dBm_000002.png
    DHO924_记录标识/
      CH1/
        帧序列/
          波形_V_000001.png
      CH2/
        帧序列/
          波形_V_000001.png
```

DHO924 和 RTM3004 的多个已记录通道使用通道目录；其他型号直接在型号目录放合图。数组只有一帧时不加“帧序列”；不同物理量、单位或横轴分别生成图片，不把不同量纲叠在同一坐标轴。标量的多次采样汇总成完整时间曲线，不逐采样点创建图片。

RTM3004 使用相同目录结构，型号目录为 `RTM3004_记录标识`，图片名按其原始物理量为 `电压_V_000001.png`。旧记录没有示波器显示元数据时使用原始电压坐标，不推测量程或偏移。

CSV、SQLite、索引和来源说明放在采集目录下的内部 `.processing-cache` 中，Windows 下该目录设为隐藏，不混入型号图片目录。缓存内的 `current.json` 指向最新完整结果；来源路径相对保存，移动整个采集目录后仍可查看。详细结构见[数据模型](../data/data-model.md#离线处理缓存-v1)。

重复点击会核对输入指纹，同版本且来源相同则复用内部缓存。PNG 清单记录版本、文件大小及 SHA256；可见图片缺失时从缓存补齐，缓存图片损坏时重新生成。新图片目录先在内部暂存并校验，完成后再替换可见目录；复制期间取消或失败保留已有图片，目录替换失败尝试恢复旧目录。被替换的目录完整保存在内部缓存的 `previous-images-*` 中，包括用户自行添加的文件。异常退出的临时目录不进入历史列表，也不视为完成结果。

旧版 `current.json/result-*` 目录仍可在 App 中读取；重新点击“处理数据”后建立新的内部缓存并整理为上述图片目录。旧目录整体保留到内部缓存，不删除原始采集数据。

兼容分段 SQLite、JSON/NPZ 单帧和旧版平铺目录。已收尾但残留 WAL 的 SQLite 在临时副本内合并读取，校验时包含 WAL，不改源数据库或旁路文件。缺失片段、损坏帧、帧数不符或未知格式明确报错；确认为零帧的记录显示无有效帧。原来的独立 `export_analysis` 导出行为不变。

## 文件管理

移动、重命名和回收站操作针对整次采集目录，包含原始文件及全部处理结果；批量采集整体操作。同名目标不会覆盖，重命名实际修改目录名。

跨磁盘先复制到目标临时目录，逐文件校验 SHA256、复核源数据未变化，再发布目标并移除源目录。操作日志保存在运行目录 `processing-operations`，重启也能从日志找到已发布目标。复制或校验失败保留源目录；源目录移除失败时保留已验证目标和剩余源文件，并报告错误。恢复不会自动重放删除，需核对日志后处理副本。

“移入回收站”需要确认，调用 Qt 系统回收站接口；失败显示原因并保留记录，不退化为永久删除。正在采集、收尾、转换或处理的记录禁止文件操作，后台执行前重新核对。文件管理验证只使用隔离副本。
