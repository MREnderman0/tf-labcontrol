## 连接与驱动

列出 `deployment_components` 组件 ID、适用系统/接口、厂商安装材料和分发依据、检测方法、安装/重启/恢复要求与离线验证状态；引用公共组件清单，未知项标待补。串口/GPIB 记录实际适配器硬件 ID，网络需求包括 DHCP/静态地址及所需协议。
