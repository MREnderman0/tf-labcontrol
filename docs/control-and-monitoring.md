# 分类控制与实时监测使用指南

## 启动与设备选择

双击根目录 `run.bat` 打开软件。先在设备管理总览扫描/添加准确资源、确认身份并连接；空库存不会填充模拟设备。驱动和配置见[实机指南](hardware-testing.md)。内部 Mock 测试与开发预览使用相同页面和隔离数据，数值明确为模拟，没有独立的演示启动入口。

左侧选择“设备管理”或“实时监测”，顶部下拉选择类型。类别内再选择设备和参数通道。功能槽位 A/B 是显示与绑定关系，不等于仪器物理 CH1/CH2；同类可连接超过两台，未绑定的设备仍可选择。

## 设置参数

信号源和电源在设备管理页调节；示波器、频谱仪、光功率、万用表、网络/相噪在实时监测页右侧调节。

1. 选择正确设备和通道，查看读回来源与更新时间。
2. 在常用或高级分组输入目标值。可输入 `1e3`；选择 kHz/MHz、mV 等单位时提交前转换为能力的基本单位。
3. 点击该功能的“应用”。仅编辑不会下发。刷新读回不覆盖未提交草稿。
4. 输出/触发/上传等弹出目标确认，取消不会执行。整机输出与独立通道输出有不同标签。
5. 结果不确定、部分执行或设备拒绝时查看结果与日志，先核对仪器面板；软件不会自动重发或回滚。

波形上传和列表设置在高级分组。导入 UTF-8 CSV/TXT，一列对应一个数组参数；允许一行表头，顺序与表格列一致。导入检查数值和范围，提交还会检查型号的样点数、相关参数和选件。曲线为输入数据预览，上传后是否载入/启用需按该型号的独立操作完成。

## 信号源紧凑面板

信号源使用专用面板：射频源集中展示频率、功率、参考时钟和 RF 输出；函数/任意波形源按通道展示波形、频率、幅度和偏置。双通道并排，四通道按两行排列，保持双列，不因窗口变窄而改成上下排列。相位、负载等在“通道设置”，脉宽/占空比和斜坡对称性根据已读回的波形显示。

- 真实设备的输入值与实际读回分开显示，模拟模式不显示重复回读行；各数值下方常驻有效范围和来源。失焦、回车、点击应用时按最终单位限幅；负数、小数、科学计数法均可使用，非法输入不保存，失焦或回车时静默恢复上一次有效值。
- 读取和应用按钮大小一致；参数没有变动时“应用修改”为灰色，有改动时亮起，改回原值后恢复灰色。每个通道只提交该区已修改的参数；另一通道和其他任务分组的草稿保留。
- 参数先校验，再通过设备工作线程逐项应用。失败后停止并分别报告已完成、失败、未执行，不自动回滚或重放。关联设置改变范围后，若剩余值需修正，会暂停并等待再次应用。
- RF / 通道输出在顶部独立操作并确认，不随参数应用开启。SMA100B 的 RF 输出限幅、功率偏移单列展示，不自动修改限幅。
- 扫频、调制、突发、列表/任意波形按型号能力分组；只读项明确标记，缺选件项显示原因。设备详情提供地址、序列号、选件和完整范围更新时间。

本轮固定使用 100% 应用界面比例，保留 Qt 的系统 DPI 处理。界面缩放和步长按钮按用户最新要求暂缓实施。窗口通常最小为 960×600（Qt 逻辑尺寸），启动时根据屏幕工作区、任务栏和窗口边框约束大小；工作区更小时最小尺寸跟随可用空间。侧栏不自动收起，通道始终双列，较低高度使用纵向滚动访问全部设置。

功能验证与独立视觉审查见[信号源界面验收记录](ui-signal-source-review.md)。

## 监测与记录

类型页勾选读取通道、数据项目与点数，点击单次读取或开始监测。默认读取台式仪器的已有数据；需要每批发起单次时勾选并确认。Pico 必须先配置/启用通道，且启动采集需要确认；3458A 读取存储的行为也需要确认。

轮询默认 0.5 s，点数对部分台式仪器仅为请求值，实际数据以仪器返回为准。当前 S 参数幅度/相位使用同一批复数数据。Pico streaming 是有限批次，不能当作无间隙无限流。

“开始监测”只在内存保留有界数据，不生成实验文件。点击“开始记录”后才逐批写入原始 CSV、NPZ 与 JSON 配置快照；“保存当前数据”只保存当前数据源最近一批，含合并读取的其他通道。停止记录会完成已开始的记录批次。“停止监测”停止软件轮询，不关闭仪器输出或替代面板 Stop。

监测中可以应用参数，软件在本批读完后串行设置和读回，再继续。调参失败只暂停该设备。页面切换、窗口缩放和扫描不停止任务。监测期间不能断开、重连或换槽；记录/控制尚未完成不能切换模式。

## 添加总览卡片

在类型页点击“添加此项目到监测总览”，或在总览点击“添加监测卡片”。卡片可改名、删除、用上下箭头调整顺序；标题点击后进入设备类型页并定位通道。多个卡片共享同源数据，不重复打开仪器。

卡片按内容区宽度自动排列，没有手动列数设置。窄窗口单列，宽窗口可超过三列；侧栏收起/展开时重排。电子学和光学分别保存卡片、顺序及数值/趋势显示方式；恢复布局不会开始监测。移除卡片仅改变显示，不停止其他页面使用的设备任务，需在类型页显式停止。

## 文件与反馈

默认根目录 `%LOCALAPPDATA%\TF-LabControl`，可用 `LAB_CONTROL_HOME` 更改。真实与模拟的库存、草稿、布局独立；演示放在 `simulation` 子目录。布局保存在 SQLite 的 workspace 表，列数不持久化。实验数据分别在 `data/electronic`、`data/optical`；日志位于 `logs`。

现场反馈请提供型号/固件、连接方式、点击步骤、目标与读回、错误文字、日志片段和原始数据；有条件时附仪器面板对照。所有真实型号当前仍为待实机验收。
