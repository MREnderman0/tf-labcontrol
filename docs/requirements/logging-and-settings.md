# 操作日志与系统设置需求

## 操作日志

顶部子菜单为全部日志、设备操作、采集与处理、异常与告警。日志至少包含时间、模式、设备、槽位或任务、操作、结果和错误原因。

需要记录扫描、连接、断开、重连、绑定、换槽、预设加载、参数应用、输出启停、采集、处理、导出、超时、断连、识别失败、数据质量异常和阈值告警。高风险批量操作记录确认结果和逐台结果。

## 系统设置

软件设置提供“环境与修复”。当前提供后台检查、取消并保留部分结果、修复方案和 JSON 报告导出；自动安装/网络修改执行器后续接入。具体状态、离线材料和执行/恢复要求见[部署与环境修复](../development/desktop-deployment.md)。检查完成不得显示为修复成功。

顶部子菜单为软件设置、数据存储、通信设置、日志设置。第一版包含主题、默认数据路径、实验保存策略、VISA/串口扫描、通信超时、重连、日志级别和保留策略。

设置中提供电子学/光学模式开关，顶栏始终显示当前模式。模式切换前检查采集和控制任务是否空闲；非空闲时禁止切换，空闲时二次确认并写日志。切换不自动重连设备、不打开输出、不发送恢复命令。
