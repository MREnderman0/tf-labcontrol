# 数据处理模块需求

首版按“单设备采集 / 批量采集”组织历史列表，支持 JW8105、M300、6362D、K+K FXE/FXE2 和 DHO924。功能包括历史数据目录索引、全量数据整理、CSV 与 SQLite 缓存、完整标量时间曲线、逐帧时间线，以及整次采集目录的移动、重命名和系统回收站操作。详细交互和边界以[使用指南](../guides/data-processing.md)为准。

型号包声明离线处理能力，公共服务只读取统一测量数据，不连接设备。可见图片在整次采集下的 `数据处理` 中按设备分别存放；CSV、SQLite 和来源索引存入隐藏的 `.processing-cache` 内部缓存。保留身份、全部数值、原精度、单位、通道、配置变化及时间来源。来源清单记录输入指纹、记录 ID、版本与状态；重复处理可复用，取消/失败保留已有完整结果。帧缓存随机读取，长记录仅显示时降采样，不补零、不插值、不假设同步。

历史列表支持按采集日期折叠，并能直接打开整次采集文件夹。App 使用深色交互图表和固定通道配色；适应全部数据以完整加载数组计算范围。示波器支持采集时各通道独立刻度及物理单位视图切换，光标与导图保留真实数值。

“处理数据”自动生成 Nature 风格白底 183 mm、600 dpi PNG，不再提供单独的手动导出或格式、尺寸选择。除型号显式声明分图的 DHO924 外，同物理量、单位和横轴的全部通道合图：标量绘制完整曲线，光谱逐帧生成；DHO924 逐帧且逐通道输出。单图直接放在型号目录，仅 DHO924 多通道按 CH 文件夹拆分，多帧数组增加“帧序列”子目录；可见型号目录不包含缓存和索引。K+K 逐帧时间戳及报告文本不作为配置断点，真实设置和会话变化、采集缺口仍断开，孤立有效点必须可见。原始数组相同的帧保持相同，不制造差异。自动图片集支持复用、缺失补建、取消和失败保护；旧布局可读，重新处理后整理为图片目录，旧文件保存在内部缓存。密集曲线分批绘制，避免 Qt 长路径阻塞界面，并在批次间检查取消。首版不包含滤波、FFT、拟合、稳定度算法和实验编排。

验收包括原始数据逐帧/逐点一致性、单帧/连续/空记录、缺失或损坏片段、未知型号、取消与重复处理、重启和移动恢复、后台绘图响应及时间线最新请求。五类现有真实历史数据用于离线验证；DHO924 另使用型号波形夹具和模拟记录，不据此声明实机验收。文件操作测试只使用隔离副本。
