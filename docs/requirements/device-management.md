# 设备管理需求与实现状态（0.3.0）

真实版与演示版共用 RealWindow、分类页和监测组件，通过 ApplicationRuntime 注入真实或 Mock 服务；库存、草稿和布局分开保存。扫描和总览的唯一详细依据为[设备发现与总览](device-discovery-and-overview.md)；监测依据为[实时监测](realtime-monitoring.md)。

## 总览

总览只显示有当前设备的类别卡片；没有当前设备的类别隐藏，历史记录不冒充本次发现。全部为空时显示扫描提示，“设备列表”保留设备池入口。点击卡片打开对应设备池，设备行按稳定 ID 增量更新，不在扫描时清空和重建。类别计数区分发现、识别、连接、未连接、未知、异常和绑定。

所有已接入设备统一使用 general 工作区，不按电子学／光学限制操作。光功率计默认提供“功率计1、功率计2、功率计3、功率计4”，内部使用 `optical_power_meter:1/:2/:3/:4`；其他类别默认提供 A/B 槽位，如信号源 A/B、电源 A/B，内部仍使用 `signal_generator:1/:2` 等标识。用户可在绑定下拉菜单输入名称并按回车新建，点击空闲槽位旁的删除按钮移除默认或自定义槽位。定义按类别持久保存，不固定槽位数量；已绑定槽位不可直接删除，删后重启不自动补回。内部 Mock 预览使用隔离模拟库存，首次绑定适用槽位，后续保留用户绑定；真实入口默认未绑定，不自动连接或打开输出。

## 分类页与参数

| 类别 | 设备管理 | 实时监测 |
| --- | --- | --- |
| 信号源 / RF | 紧凑通道卡片中的波形、电参数与输出，以及参考源弹窗；高级协议能力不等于 GUI 入口 | 设置读回与状态 |
| 普通直流电源 | 连接及能力概况，旧控制入口进入监测 | 电压、电流、输出和型号支持的测量、参数控制 |
| 芯明天 XMT/E00 控制器 | 专属常规／标准波形控制页，按型号能力和当前状态限制操作 | 不提供监测入口；不能把未确认单位的原始帧当作物理测量 |
| 示波器 / 频谱仪 | 身份、连接、通道和能力概况，进入监测 | 当前紧凑页面支持的采集、显示参数与波形/轨迹 |
| 光功率 / 万用表 / 网络 / 相噪 | 连接及能力概况 | 数值/轨迹与测量参数 |
| 光谱仪 | 连接及能力概况，进入监测 | Ceyear 6362D 的波长、扫描参数与光谱轨迹；具体支持范围见型号说明 |
| 温控 / 负载 / 泵浦 | 隔离模拟参数，标注待补型号/协议 | 模拟数据；真实未知设备没有操作入口 |

页面按类别显示设备、槽位、身份、资源、连接状态和适用通道。已开放控件使用 CapabilitySet 校验能力、范围与选件；底层已注册操作不保证存在 GUI 控件。[能力矩阵 JSON](../generated/capability-matrix.json)记录协议能力、中文标签和型号所在页面，不推断逐操作的界面位置。当前入口以[控制与监测指南](../guides/control-and-monitoring.md)为准。

数值支持科学计数法及常见单位换算，枚举下拉、布尔开关、动作按钮。UI 收紧型号通道范围与用户 limits，适配器再次检查关联限制。输入只改变草稿，点击对应“应用”才提交；输入期间即标记草稿，读回不会覆盖未提交值。草稿按 general/设备 ID/通道/操作保存，兼容迁移旧模式草稿。

read_settings 返回带来源、UTC 时间和质量的 ParameterReading，分别显示仪器读回、本会话设置记录、模拟值、未知。失败保留目标、旧读回与执行原因，不重发/回滚。波形上传和列表设置的协议能力及兼容编辑组件仍保留，当前简洁信号源页面不开放相关入口。已开放的输出等动作沿用能力确认规则，确认框显示目标、资源、作用域与参数。无任意厂家命令输入。

## 操作

已实现扫描、取消、环境诊断、手工资源添加、单台/一键连接、停止批量连接、断开、重连、身份刷新、状态读取、能力/诊断查看、显示名、槽位和主资源选择。总览一键连接全部当前发现的可连接设备，最多 4 台并行、失败继续，保留已有会话并提供结果明细；同一设备保持串行与资源锁，扫描和批量连接互斥。停止连接跳过排队项并等待所有在途连接完成。连接不打开输出、不复位、不恢复预设。未知型号可保留和诊断；选择准确适配器后才允许连接和能力操作。

同一设备按稳定 ID 或可靠完整身份复用历史槽位；同型号其他设备保持未绑定。已占用的兼容槽位可以选择，确认替换后原占用设备保持连接、在通用工作区内解除绑定，新设备原槽位释放。双方变更原子保存，失败均保持原绑定；取消不修改。新绑定统一保存到 general，旧模式绑定保留，主动解绑和被替换后的空绑定不因扫描或重连而恢复。

每台设备任务串行。采集/控制/连接期间禁止断开、重连、换槽及切换主资源；先请求停止并等待当前任务完成。断开仅释放本软件句柄，不表示仪器输出已经关闭。

扫描不得调用既有会话的 open/close/disconnect，不为识别插入额外查询；资源未发现只能影响发现状态，不能把连接状态改成断开。

## 验收入口

软件自动化覆盖字段、操作锁定、稳定行、通用工作区与旧设置兼容行为、CLI 和无硬件环境。现场须以 6–20 台设备重复扫描并保留采集，记录驱动缺失、超时、插拔和别名状态；步骤见[实机指南](../testing/hardware-testing.md)。每台设备仍需逐能力验收，不因总览能连接就标记“可控”。
