# 设备管理需求与实现状态（0.3.0）

真实版与演示版共用 RealWindow、分类页和监测组件，通过 ApplicationRuntime 注入真实或 Mock 服务；库存、草稿和布局分开保存。扫描和总览的唯一详细依据为[设备发现与总览](device-discovery-and-overview.md)；监测依据为[实时监测](realtime-monitoring.md)。

## 总览

总览始终显示所有已注册类别，0 台时也保留类别卡片。类别下的设备行与右侧详情抽屉位于同一页；按稳定 ID 增量更新，不在扫描时清空和重建。类别计数区分发现、识别、连接、未连接、未知、异常和绑定。

电子学/光学模式只影响适用性和槽位候选，不隐藏设备、不断开连接、不重建库存。每类预留 A/B 槽位，如信号源 A/B、电源 A/B，内部仍使用 `signal_generator:1/:2` 等标识。演示入口加载 24 台 Mock，首次绑定适用槽位，后续保留用户绑定；真实入口默认未绑定，不自动连接或打开输出。

## 分类页与参数

| 类别 | 设备管理 | 实时监测 |
| --- | --- | --- |
| 信号源 / RF | 波形、电参数、输出、调制、扫频、突发、参考时钟、上传等已注册能力 | 设置读回与状态 |
| 电源 | 电压、电流、独立/整机输出、保护、跟踪、定时、列表、远端采样等型号能力 | 电压/电流测量及趋势 |
| 示波器 / 频谱仪 | 身份、连接、通道和能力概况，进入监测 | 影响显示的全部已注册参数与波形/轨迹 |
| 光功率 / 万用表 / 网络 / 相噪 | 连接及能力概况 | 数值/轨迹与测量参数 |
| 温控 / 负载 / 泵浦 / 光谱仪 | 隔离模拟参数，标注待补型号/协议 | 模拟数据；真实未知设备没有操作入口 |

顶部统一显示设备、槽位、身份、资源、连接状态、通道。CapabilitySet 驱动常用、高级、状态与诊断控件；未注册功能没有执行按钮，缺选件项禁用并说明原因。每项操作的页面位置和中文标签同步生成到[能力矩阵 JSON](../generated/capability-matrix.json)。

数值支持科学计数法及常见单位换算，枚举下拉、布尔开关、动作按钮。UI 收紧型号通道范围与用户 limits，适配器再次检查关联限制。输入只改变草稿，点击对应“应用”才提交；输入期间即标记草稿，读回不会覆盖未提交值。草稿按模式/设备 ID/通道/操作保存。

read_settings 返回带来源、UTC 时间和质量的 ParameterReading，分别显示仪器读回、本会话设置记录、模拟值、未知。失败保留目标、旧读回与执行原因，不重发/回滚。波形/列表提供可编辑表格、UTF-8 CSV/TXT 导入、点数/范围校验和非实测预览。输出启停、触发、归零、上传沿用能力确认规则，确认框显示目标、资源、作用域与参数。无任意厂家命令输入。

## 操作

已实现扫描、取消、环境诊断、手工资源添加、连接、断开、重连、身份刷新、状态读取、能力/诊断查看、显示名、槽位和主资源选择。连接不打开输出、不复位、不恢复预设。未知型号可保留和诊断；选择准确适配器后才允许连接和能力操作。

每台设备任务串行。采集/控制/连接期间禁止断开、重连、换槽及切换主资源；先请求停止并等待当前任务完成。断开仅释放本软件句柄，不表示仪器输出已经关闭。

扫描不得调用既有会话的 open/close/disconnect，不为识别插入额外查询；资源未发现只能影响发现状态，不能把连接状态改成断开。

## 验收入口

软件自动化覆盖字段、操作锁定、稳定行、原模式行为、CLI 和无硬件环境。现场须以 6–20 台设备重复扫描并保留采集，记录驱动缺失、超时、插拔和别名状态；步骤见[实机指南](../testing/hardware-testing.md)。每台设备仍需逐能力验收，不因总览能连接就标记“可控”。
