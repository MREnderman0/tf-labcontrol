# 光频梳热试验数据处理需求

需求来自《KX-11 时频比对分系统光学频率梳电学箱初样鉴定件热试验测试细则》v0（2026-11-02）附录的冷热启动及科学实验流程。本页记录试验要求和实现范围。首批六项的输入、参数及输出契约待逐项确认。

## 首批确认范围

六项的测量数据统一通过 MCP `acquire_once` 获取。按下表顺序确认各项对应的设备、采集模式和测量数据类型，再确认采集与计算参数，最后确认客户端所需的输出量、单位和判定口径。

| 项目 | 细则要求 | 实现前待确认 |
| --- | --- | --- |
| 温控稳定性 | 对光梳光栅、光谱光栅、PPLN-A、PPLN-B、PDH-EOM 的温度序列计算峰峰值。测量窗口为 4000 s，按已有环内、环外通道分别计算。精密温控峰峰值限值为 10 mK，普通温控为 100 mK。 | 当前确认单通道、每帧一个数字，由客户端转换单位。待确认设备型号、通道与环内外映射、窗口起点及缺样判据。附录的 PDH-EOM 行只列环内，且限值单位未写全。 |
| 射频功率波动 | 按射频通道计算平均功率和相对室温结果的偏差。平均功率按通道范围判定，相对室温偏差小于 2 dB。 | 暂缓，疑似载荷端测量，归属待核实。恢复后确认遥测及室温基线来源、样本单位、平均口径、统计窗口和输出。 |
| 光功率监测 | 将监测光功率与经插损修正的参考光功率比对，偏差不超过 20%。用 10–700 µW 多档数据算监测电路增益，0 µW 数据算噪声标准差，300 µW 数据评估功率波动。附录要求噪声标准差小于 10 mV，功率波动不超过 0.5%。 | 已确认从多通道光功率计取得各通道的功率读数。待确认是否需要参考比对、参考值来源和通道映射、插损参数及波动公式。监测电路增益和电压噪声所需的数据来源待确认。 |
| 电压波形与反馈驱动 | 从电压科学数据和仪器波形计算均值、峰峰值与纹波，检查周期振荡。评估 PZT、EOM、AOM 反馈驱动范围、调节精度和波动。 | 波形、设定值及步进序列来源，采样率及统计区间，振荡判据，驱动量输出。 |
| 频谱、噪声与增益 | 从 ADC 原始样本、ADC 频谱或外部仪器数据提取峰值频率与功率、信噪比、杂散抑制比，按测试项计算噪声谱密度、频带积分噪声、相位噪声及通道增益。细则分别给出 RBW、偏频和积分频带等条件。 | 各测试项实际输入是时域样本还是频谱，单位和标定，采样率、频谱估计与积分参数、指标输出。 |
| 相位温漂与频率稳定度 | 根据误差信号和温度测量环外相位漂移。对 PDH 误差信号换算频率，并用 Stable32 分析频率计数数据的稳定度。1397 主备流程列出 4000 s 采集、频率计数门时间 1 s，以及 1 s 和 1000 s 的判据。 | 温度与误差信号的对齐方式，鉴频及相位标定，计数数据的格式、稳定度统计方法、平均时间及输出。 |

### 温控稳定性处理函数

[`temperature.stability`](../../src/lab_control/domain/temperature_metrics.py) 按同一通道的已选标量帧计算 `peak_to_peak = max - min`，计算参数为空。每帧必须包含该通道的一个有限实数标量，且不带横轴。不符合要求的帧会导致校验失败。输入为空或仅有一帧时返回 `null`，质量为 `unavailable`。结果保留输入数值尺度，单位转换由客户端负责。函数以提交的帧集合为计算范围，4000 s 窗口选取及合格判定留在试验流程层。设备型号绑定和 `start_experiment` 的已有记录输入仍待接入。

## 其余已记录需求

- 指令执行校验。按步骤核对电压、电流、温度、功率、开关、主备状态及计数变化。记录实测值和异常，指定步骤高亮并写错误日志。
- 通信及存储完整性。比对 LVDS、RS422 回环文件及 DDR 读回数据，检查 RS01 是否在规定时间内应答。
- 环路开环增益。解码 VNA 数据，计算各环路在 1 Hz 的开环增益及其波动。
- 试验留档。按循环、温段和步骤记录结果，保留遥测及科学数据，并记录异常。

## MCP 接入边界

已确认客户端先采集，再计算。客户端调用 `acquire_once` 采集并保存一帧，任务完成后取得 `recording_id`，再将一个或多个记录 ID 交给 `start_experiment`。单帧仅有各通道的单点读数时，时间序列由多帧建立。记录列表的接口字段、校验和组合规则待确认。

按当前[远程指标处理契约](../architecture/remote-metrics.md)，`start_experiment` 由服务端发起有限采集，`start_processing` 接收单份已有记录。首批需求需要扩展 `start_experiment` 的已有记录输入。客户端通过 `get_processing_capabilities` 查询支持项及参数定义，提交后用 `get_task_status` 查询进度，完成后用 `get_processing_result` 读取带单位和质量标记的指标。任务完成与试验合格分别判断。

细则中部分输入文件以 `xx` 占位，MATLAB 脚本名用于追溯试验步骤。
