# 光频梳热试验数据处理需求

需求来自《KX-11 时频比对分系统光学频率梳电学箱初样鉴定件热试验测试细则》v0（2026-11-02）附录的冷热启动及科学实验流程。本页记录试验要求、首批实现和暂缓项目。

## 首批确认范围

测量数据按项目保存为单帧或连续记录，再提交指标处理。按下表顺序确认对应的设备、采集模式和数据类型、采集与计算参数，以及输出量、单位和判定口径。

| 项目 | 细则要求 | 实现前待确认 |
| --- | --- | --- |
| 温控稳定性 | 对光梳光栅、光谱光栅、PPLN-A、PPLN-B、PDH-EOM 的温度序列计算峰峰值。测量窗口为 4000 s，按已有环内、环外通道分别计算。精密温控峰峰值限值为 10 mK，普通温控为 100 mK。 | 当前确认单通道、每帧一个数字，由客户端转换单位。待确认设备型号、通道与环内外映射、窗口起点及缺样判据。附录的 PDH-EOM 行只列环内，且限值单位未写全。 |
| 射频功率波动 | 按射频通道计算平均功率和相对室温结果的偏差。平均功率按通道范围判定，相对室温偏差小于 2 dB。 | 暂缓，疑似载荷端测量，归属待核实。恢复后确认遥测及室温基线来源、样本单位、平均口径、统计窗口和输出。 |
| 光功率监测 | 将监测光功率与经插损修正的参考光功率比对，偏差不超过 20%。用 10–700 µW 多档数据算监测电路增益，0 µW 数据算噪声标准差，300 µW 数据评估功率波动。附录要求噪声标准差小于 10 mV，功率波动不超过 0.5%。 | 已确认多通道光功率计的自身波动及参考偏差公式。待确认参考功率的插损修正流程，以及监测电路增益和电压噪声所需的数据来源。 |
| 电压波形 | 从电压科学数据和仪器波形计算均值、峰峰值与纹波，检查周期振荡。 | 已确认用示波器 `acquire_once` 的整段波形逐通道计算，纹波直接取峰峰值。共享指标另提供 RMS 和总体标准差。周期振荡检查暂缓。 |
| 频谱、噪声与增益 | 从 ADC 原始样本、ADC 频谱或外部仪器数据提取峰值频率与功率、信噪比、杂散抑制比，按测试项计算噪声谱密度、频带积分噪声、相位噪声及通道增益。细则分别给出 RBW、偏频和积分频带等条件。 | 已确认主峰、信噪比和杂散抑制比使用频谱仪 `acquire_once` 保存的普通扫频轨迹。主峰取整条轨迹的最高点，底噪与最高杂散分别取距主峰超过 2 MHz 的 dBm 点的算术平均值与最大值。噪声谱密度和带内积分噪声暂缓。相位噪声从相噪仪曲线按客户端指定偏频取值，采样点之间插值。ADC 通道增益由载荷侧处理。 |
| 相位温漂与频率稳定度 | 根据误差信号和温度测量环外相位漂移。对 PDH 误差信号换算频率，并用 Stable32 分析频率计数数据的稳定度。1397 主备流程列出 4000 s 采集、频率计数门时间 1 s，以及 1 s 和 1000 s 的判据。 | 环外相位温漂由载荷侧处理。频率稳定度暂缓。 |

### 温控稳定性处理函数

[`temperature.stability`](../../src/lab_control/domain/temperature_metrics.py) 按同一通道的已选标量帧计算 `peak_to_peak = max - min`，计算参数为空。每帧必须包含该通道的一个有限实数标量，且不带横轴。不符合要求的帧会导致校验失败。输入为空或仅有一帧时返回 `null`，质量为 `unavailable`。结果保留输入数值尺度，单位转换由客户端负责。函数以提交的帧集合为计算范围，4000 s 窗口选取及合格判定留在试验流程层。实际温控仪型号及其能力绑定待确认。

### 光功率监测处理函数

[光功率处理函数](../../src/lab_control/domain/optical_power_metrics.py)读取各通道的标量功率帧。记录为 dBm 时先换算到 W。处理范围为客户端选定的帧集合。

| Profile | 算法参数 | 逐通道输出 |
| --- | --- | --- |
| `optical_power.fluctuation` | `{}` | `chN.fluctuation_percent` 等于 `(最大功率 − 最小功率) / 平均功率 × 100`。通道少于两个读数或平均功率为零时，指标为 `unavailable`。 |
| `optical_power.reference_deviation` | `reference_power_w`，例如 `{"1": 0.0003, "9": 0.0002}`。键为通道号字符串，每个采集通道对应一个正的参考值，单位为 W。 | `chN.min_deviation_percent` 和 `chN.max_deviation_percent` 为逐点 `(实测功率 − 参考功率) / 参考功率 × 100` 的最小值和最大值，保留正负。 |

两个算法已绑定 PM100D 和 JW8105，通过 `start_experiment` 接收已有记录。插损修正及试验判定仍待确认。

### 电压波形统计处理函数

[`voltage.waveform_statistics`](../../src/lab_control/domain/voltage_waveform_metrics.py) v2 接收一次示波器采集的波形帧，使用每个通道全部 `values` 样本。波形标签为 `voltage` 或 `waveform`，样本单位为 V，横轴 `axis` 单位为 s。计算参数为 `{}`，输出 `chN.mean`、`chN.peak_to_peak`、`chN.rms`、`chN.std`，单位均为 V。RMS 包含直流分量，标准差采用总体口径（`ddof=0`）。纹波取 `chN.peak_to_peak`，换算为 mVpp 时乘以 1000。单样本的 RMS 取绝对值，标准差为零，峰峰值标记为 `unavailable`。多次采集分别提交。周期振荡检查暂缓。

### 频谱主峰、信噪比与杂散抑制比

[`spectrum.peak_and_snr`](../../src/lab_control/domain/spectrum_metrics.py) 接收一帧普通扫频轨迹。采集前通过设备参数设置扫频范围和 dBm 幅值单位，计算参数为 `{}`。`peak_frequency`（Hz）和 `peak_power`（dBm）取整条轨迹的最高点，并列时取较低频率。对距主峰超过 2 MHz 的点，`snr`（dB）取峰值功率减去其 dBm 算术平均值，`spur_rejection`（dB）取峰值功率减去其最高 dBm 读数。没有区外点时保留峰值结果，两项差值均标记为 `unavailable`。

### 指定偏频的相位噪声

[`phase_noise.at_offset`](../../src/lab_control/domain/phase_noise_metrics.py) 接收 `acquire_once` 保存的一帧相噪数据，选择 `phase_noise` 曲线。每次由客户端通过 `offset_hz` 传入一个正偏频。目标频率落在采样点时直接返回该点，在相邻点之间按 Hz 轴对 dBc/Hz 值做线性插值。结果为 `phase_noise`，单位为 dBc/Hz。超出曲线范围时标记为 `unavailable`。

## 其余已记录需求

- 指令执行校验。按步骤核对电压、电流、温度、功率、开关、主备状态及计数变化。记录实测值和异常，指定步骤高亮并写错误日志。
- 通信及存储完整性。比对 LVDS、RS422 回环文件及 DDR 读回数据，检查 RS01 是否在规定时间内应答。
- 反馈驱动端范围和调节精度。PZT、EOM、AOM 的设定、步进与验收归入试验操作流程。
- 环路开环增益。解码 VNA 数据，计算各环路在 1 Hz 的开环增益及其波动。
- 试验留档。按循环、温段和步骤记录结果，保留遥测及科学数据，并记录异常。

## MCP 接入边界

客户端调用 `acquire_once` 采集并保存一帧，任务完成后取得 `recording_id`，再以 `recording_ids` 列表交给 `start_experiment`。多条记录必须来自同一台设备，且各含一帧。温控和光功率指标支持按列表顺序读取多帧，示波器、频谱仪和相噪仪的处理项每次提交一份记录。

客户端通过 `get_processing_capabilities` 查询处理项、参数定义及是否支持多份记录，提交后用 `get_task_status` 查询进度，完成后用 `get_processing_result` 读取带单位和质量标记的指标。完整字段见[远程指标处理契约](../architecture/remote-metrics.md)。任务完成与试验合格分别判断。

细则中部分输入文件以 `xx` 占位，MATLAB 脚本名用于追溯试验步骤。
