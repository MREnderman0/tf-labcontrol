# 数据采集模块需求

## 页面

顶部子菜单为采集配置、采集中、历史记录。采集配置选择当前模式的功能块、设备、通道、测量量、采集频率、持续时间和保存策略。

## 采集行为

- 支持 6–20 台设备同时在线和多设备联合采集。
- 实时查看不自动创建实验记录；点击开始采集后创建记录并持久化。
- 实验记录保存模式、预设、设备身份、槽位绑定、关键设定、采集参数、起止时间和数据质量。
- 采集任务状态为准备、运行、停止、完成、失败或部分失败。
- 实际使用的功能块必须已绑定设备；未使用的空槽位不阻塞任务。
- 分别记录设备采样率、软件轮询频率和界面刷新频率。
- 软件轮询不默认宣称硬件同步；同步精度和触发方式按实验另行确认。
- 超时、断连和无效数据使用质量标记，不用零值替代，并写入操作日志。

## 模式隔离

电子学和光学实验记录使用独立目录和命名空间。模式切换不能发生在采集或控制任务运行期间，已保存记录不跨模式合并。
