# 实时监测设计与实现（0.3.0）

本文件是实时监测页面、布局和任务行为的当前依据；操作步骤见[控制与监测指南](../guides/control-and-monitoring.md)。当前统一使用 general 工作区，不提供电子学／光学模式切换；旧模式标识只保留历史兼容。本轮没有阈值告警、自由拖拽/缩放、自动实验编排或历史数据处理工作台。

## 页面分工

实时监测的子页以总览为固定入口，其余设备类别标签只在该类别存在已连接会话时显示；类别最后一台设备断开后自动回到总览。总览显示所有已连接且存在数据源的设备，每台设备一张卡片，按设备类别分组，包含光功率计。卡片主面显示设备名称、功能槽位、采样间隔、“参与采样”复选框和紧凑运行状态，右侧“详情”为可点击文字；设备身份、保存位置、已保存帧数和 CSV 转换状态在详情弹窗中查看。勾选状态按通用工作区的功能槽位保存，槽位更换设备后沿用上次选择。右上角“一键开始采样”只为勾选设备创建记录任务，未勾选设备不会发起请求；任务运行时同一按钮停止采样。断开会话的设备立即从总览移除。其余设备类别页共用设备选择器，显示功能槽位（功率计1～4，其他类别 A/B）、型号、资源、连接状态和通道。

信号源的写入参数在设备管理，监测页展示设置读回，不伪装成输出波形。电源、示波器、频谱、万用表、网络/相噪的工作参数放在监测页右侧。电源采用上下电压／电流趋势与紧凑通道卡片，每周期共用一个标量采集；旧控制路由转入实时监测，设备池不重复提供控制入口。温控/负载/泵浦/光谱未知型号仅有隔离 Mock 演示，不能向真实未知设备写入。

光功率计是监测专属页面：设备管理仍显示“光学测量”分类卡片和连接流程，但不显示光功率计控制子页，旧入口直接跳转到“实时监测 → 光功率计”。页面一次展示能力快照中的全部通道，复选框同时控制曲线、读数卡片和采集请求；首次使用全选，之后按功能槽位持久化。采集中切换通道会使当前请求结果失效并刷新请求集合，监测任务保持运行；取消全部时只暂停采集，重新勾选后恢复。每个有效帧追加一个点，趋势最多保留 1200 点且不超过 600 秒。“开始监测”只启动显示采集，“开始记录”才逐帧保存，停止时等待二进制收尾。主显示统一为 W：W 原值直接显示，dBm 只在显示层按 `10 ** ((dBm - 30) / 10)` 换算；原始批次、单位和导出文件保持设备返回值。波长在仪器面板设置，页面不显示波长参数卡片或触发波长同步；JW8105 采集使用显示功率命令 `0x0162`，不把模块数值波长当作各通道预置波长保存。右侧功率读数由通道卡片负责，卡片固定紧凑尺寸，数值显示 6 位有效数字，完整值可悬停查看。

参数控件来自 CapabilitySet，中文标签在 application/controls.py。未注册的功能没有执行按钮，缺选件项显示原因并禁用。普通监测的单次读取、开始/停止监测、保存当前数据和开始/停止记录是独立动作；仪器运行/停止/触发仍是单独的能力操作。相噪仪使用下述有限任务，开始采集同时授权测量与保存。

## 总览卡片与布局

卡片由当前已连接且存在数据源的设备自动生成，每台设备只有一张。设备按类别分组，卡片主面显示设备名称、通用工作区的功能槽位、采样间隔、“参与采样”复选框、紧凑运行状态和“详情”文字；厂家、型号、序列号、保存位置、已保存帧数及记录转换说明在详情弹窗中查看。总览不显示实时曲线或读数。记录中及二进制收尾期间卡片显示红色描边，断开会话后从总览移除。槽位只用于确认和保存选择，不把 COM/IP 当物理身份。点击设备名称进入对应类型页。

每个设备类别独占一组行，类别之间纵向排列；同类设备横向排列，每行最多三台，第四台换行，下一个类别另起新行。同类列数按 `min(3, max(1, floor((内容宽度 + 16) / (360 + 16))))` 计算。360 为目标最小宽度，16 为间距，单位均为逻辑像素；窄窗口减为两列或一列，同行等宽，超出高度纵向滚动。没有列数选择器。窗口和侧栏宽度变化只移动现有卡片对象，保留顺序、选择与任务；设备列表不变时的状态刷新不重建网格。

总览统一保存卡片的参与采样状态和设备级采样间隔，不保存列数。间隔的 canonical 设置为 `monitor-timing/general/<device>`，总览卡片与设备页共用并双向同步；旧的总览偏好只在缺少设备级设置时迁移一次。参与采样状态以通用工作区和功能槽位为键，槽位更换设备后沿用；无槽位设备使用稳定设备 ID。进入总览不会自动启动采样，右上角统一开始或停止勾选设备的记录任务。切换设备或页面后，各监测页从 `MonitoringService.latest()` 恢复最后一帧有效图形或读数，不重新访问仪器。

总览与设备页的间隔输入允许中间文本及越界草稿，失焦或回车后才校验并应用；刷新与其他设备的同步不得覆盖正在输入的文本。完成编辑后越界数值收敛到边界，空白和非数值恢复上次有效值。设备有槽位时，保存目录、记录说明、CSV 和清单标注接受保存操作时的槽位，后续改绑不影响已有记录。

总览修改采样间隔同时将该设备切换为自定义节奏，更新活动任务、设备页模式和持久化偏好；不能只保存数值却继续最快采集。切换参与采样状态和修改其他设备保留原节奏。旧总览独立间隔按自定义节奏迁移，已有设备级选择不被覆盖。

## 数据显示

| 数据源 | 显示与约束 |
| --- | --- |
| 示波器 | 多通道时域波形；Pico 可选有限 streaming 批次 |
| 频谱仪 | 频率轨迹；零跨度采用设备返回的秒轴 |
| 光功率/万用表/电源 | 当前读数与有界趋势；保留单位和质量 |
| 网络分析仪 | 当前复数 S 参数的幅度 dB / 相位 °，共享一次采集 |
| 相噪仪 | 定时相位采集、相噪、重叠 ADEV/MDEV；高级 AM 与旧数据流接口暂不加入专属页面 |
| 信号源 | 频率、幅度或功率、输出的设置读回，不是实测波形 |

PyQtGraph 使用软件绘制与 peak 抽稀；导出保存未抽稀原始数据。每个标量显示序列最多保留 1200 点且不超过 600 秒；后台按设备/数据源保留最新帧，标量另保留最多 1200 帧用于隐藏页恢复。示波器／频谱仪首次默认自定义 0.5 秒，可选最快或 0.5～60 秒；电源首次默认 1 秒，只提供 1、5、10、60 秒四档。所有类别的选择按通用工作区及设备持久化并在重启后恢复，间隔表示目标请求开始间隔，不代表固定采样时间。不同数据源请求轮转，以请求开始时刻计算间隔；慢读取结束后不再额外等待完整间隔，也不补发积压请求。页面显示实际有效帧接收间隔；这不是仪器采样率，也不保证实时硬件同步。

图上显示主机 UTC 更新时间、测量单位、数据质量、配置版本和任务状态。暂停或失败保留最后有效画面及原因；没有数据不会补零。不同配置版本的旧帧不能覆盖新结果。无间隙无限流、多 S 参数自动轮换、数学波形和完整分段采集未开放。

## 相噪仪定时采集

正式“实时监测 → 相噪仪”页面集中提供采样率、采集时长、输入/参考自动或手动频率、开始/停止、进度及数据目录。采样率和时长按通用工作区及设备持久化，首次默认 100 samples/s、60 秒，切换设备和重启恢复并校验能力及范围。上方显示相噪，下方显示 ADEV/MDEV；到时或提前停止后保留有效结果。旧设备管理入口转入同一页面，恢复偏好、切页和连接不会自动开始或写入仪器。

53100A 托管 USB 连接开放 1、10、100、1000 samples/s，时长 10～86400 秒且总相位点数不超过 4,000,000。时长从首个有效相位样本计算；采样率决定相位流与最小 τ，不等于界面刷新率或相噪频谱上限。参数在采集及二进制收尾期间锁定，正常使用保留所选设置。具体协议、点数约束与算法以[型号说明](../../src/lab_control/instruments/devices/microchip_53100a/README.md)为准。

此任务不使用普通监测的轮询间隔；一次启动持续读取，逐段校验并自动保存，停止还须核对仪器状态。提前停止标为部分时段，通信或连续性错误立即中止且不重放写入，停止未确认时显示最终状态未知。原始相位与统计量进入公共有界流水线；相噪沿用各次实际查询时间，不能把缓存频谱算作新的采样结果。当前软件及模拟回归通过，带 DUT/参考信号的实机采集和物理性能仍未测试。

## 调度与控制

MonitoringService 调度原 SessionManager worker，每台设备只有一个通信执行队列。相同 kind/quantity 合并通道后分发到各卡片；新请求的点数/采集选项替换相同数据源的旧选项，不创建第二会话。不同请求在该 worker 顺序执行。

应用参数先完成当前读取，再执行整组设置/读回和错误检查，增加配置版本，然后继续下一批。参数拒绝、部分执行、不确定或通信错误暂停目标设备；其他设备继续。没有自动重发、回滚或恢复输出。

完整有效回包中的配置变化属于无效帧，不等同连接中断；丢弃且不保存，后续轮询有界等待稳定。具体分类、最长 30 秒等待及单次读取约束见[监测一致性与调度规则](../architecture/live-acquisition.md)。电源、示波器和频谱仪设备池只保留一个“实时监测”入口，旧设备管理路由继续转入同一页面。

普通监测停止时只停止软件读取；当前 I/O 返回后完成停止，不发送仪器输出关闭。有限测量按型号的停止流程收尾。运行期间禁止断开、重连、换槽。切页和扫描不停止任务，扫描只用活动会话缓存。停止记录会等待已授权的在途批次和二进制写盘结束，再释放参数锁；CSV 转换继续后台执行。

停止后的在途读取、准备取消、重连清理和二进制排空期间，单设备开始及单次采集按钮禁用并显示停止状态。总览有勾选设备仍在收尾时禁用一键开始，入口同时检查，避免快速停启时只启动部分设备。收尾完成后恢复按钮；后台 CSV 不阻止下一批启动。

## 记录与保存

所有设备的采集间隔及节奏按通用工作区及设备持久化，软件启动恢复上次有效选择；不因重新进入页面或 Auto 重置。总览优先使用设备级设置，旧卡片间隔只在缺少设备级设置时迁移一次。纯监测不创建实验数据文件，布局、草稿、采集偏好与审计持久化。公共控件统一普通监测节奏：电源为 1、5、10、60 秒（首次默认 1 秒），其他轮询页面为最快或 0.5～60 秒自定义间隔；开始记录后逐帧保存，无独立保存间隔。二进制写入与采集并行，有界缓冲最多 64 帧或 128 MiB，满时明确暂停记录并排空；不静默漏存。CSV 后台固定每 5 秒转换，停止后补齐。用户停止记录前已经提交的记录读取仍完成保存。手动“保存当前帧”导出图上实际显示的完整数据及原配置来源，不重新访问仪器；慢写盘不阻塞监测和调参。

新记录路径来自软件设置的“数据保存一级目录”，默认运行目录下的 `data`。总览一次启动至少两台有效勾选设备时，按批量采集、本地日期、毫秒开始时间与共用批次标识分层，每台设备在批次内独立保存并保留槽位；每次重新启动新建批次。单台及单帧保存继续按单设备采集、本地日期、毫秒时间与设备身份分层。类型为 `continuous` 或 `single_frame`，模式保存在元数据中。开始时固定路径，跨午夜、排队写盘及更改设置不改变正在保存的目录；单台准备失败撤销该设备记录状态及参数锁，其他设备不受影响，不自动改存其他位置。真实与模拟的设置及数据保持隔离，旧目录保留。详见[数据模型](../data/data-model.md)。单帧导出与连续分段记录分别保留原始帧时间、通道、数值、坐标、单位和质量，不能把连续记录视为每帧一组 NPZ/CSV 文件。SDK 无硬件读回的设置明确来自本会话缓存；未知保持未知。

## 验收

自动化覆盖能力页面分配、单位/布尔读回、中文 CSV、草稿和确认取消、20 台并行监测与扫描、实时调参顺序、故障隔离、数据共享、纯监测不落盘、记录保存及槽位标注、旧布局兼容、隐藏页恢复、单列/三列重排及类别换行。主要页面做离屏检查。现场仍须逐设备核对参数、轴缩放、输出和断连，详见[实机指南](../testing/hardware-testing.md)。
