# 输入范围和会话能力

连接、重连、手动刷新及参数应用后，由设备 worker 创建能力快照。快照包含设备身份、选件、各通道范围、来源、UTC 时间、版本和过期状态，GUI、CLI、会话写入校验共用。前端线程不查询仪器。范围查询失败保留最后数值并标记过期，不扩大范围；写入前必须重新查询成功。

SMA100B 使用已经实机验证的 `SOUR:FREQ? MIN/MAX`、`SOUR:FREQ:STAR? MIN/MAX`、`SOUR:FREQ:STOP? MIN/MAX`、`SOUR:POW? MIN/MAX`，附带 `*OPT?`、`SOUR:POW:OFFS?` 和 `SOUR:POW:LIM?`。现场一台设备的读回为 8 kHz～12.75 GHz、−145～+40 dBm，RF 输出限幅 +20 dBm，偏移 0 dB；具体身份与原始读回保存在运行目录测试台账。这是该会话的可设范围，不保证所有频率下的物理输出功率。

功率编辑保留可设范围，不随 RF 限幅缩小，也不修改仪器限幅。列表、调制、选件等独立功能继续采用各自已核实约束。其他型号使用所引用手册的型号/通道范围，不能把 SMA 查询移植到任意 SCPI 设备。`config.limits` 以参数基准单位指定进一步收紧的上限，允许负 dBm；不能扩大型号或实机范围。

## 编辑规则

- 每个数值字段常驻显示最小值、最大值、当前单位和范围来源；未知边界明确标为未确认。
- 输入完成（失焦、回车、应用）后：高于上限改为上限，低于下限改为下限，回填草稿并提示。修正本身不调用设备写入。
- 单位选择按最终单位计算，避免点击单位菜单时先按旧单位限幅。接受负数、小数、科学计数法；空值、非法文本、NaN、无穷大和非整数的整数输入报错。
- 动态范围变化时更新提示。正在编辑的字段在编辑完成时处理；未编辑草稿和恢复的草稿按当前范围修正。原始仪器读回独立显示，始终保留真实值。
- 手工表格编辑同样限幅；CSV/TXT 导入报告超界行，整批数据不会被静默改写。
- 后端仍严格拒绝越界命令。CLI 和直接调用兼容层都不得把错误请求悄悄修改后下发。

CLI 可执行 `refresh-capabilities` 获取完整会话快照，`test` 报告包含同一快照。实机测试应记录设置范围、RF 限幅、读回值、原始错误、软件测试结果，并把依赖可用与设备已验收分开。
