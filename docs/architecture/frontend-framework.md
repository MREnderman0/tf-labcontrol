# Python 前端结构（0.3.0）

当前 `lab-control` 和 `lab-control-demo` 共用应用窗口、分类控制和监测组件，分别注入真实与 Mock ApplicationRuntime。扫描细节见[设备发现与总览](../requirements/device-discovery-and-overview.md)，参数和任务细节见[设备管理](../requirements/device-management.md)与[实时监测](../requirements/realtime-monitoring.md)。数据处理、完整实验编排和阈值告警尚未实现。

## 1. 目标形态

前端使用 PySide6 + Qt Widgets，固定为[用户确认的历史分类卡片版](../../direction-approved.md)：左侧一级导航、顶部分类标签、侧栏底部模式与真实/演示标识。扫描入口位于顶栏；首页采用三列分类卡片，窄窗口减少列数。

PySide6 只负责界面和 Qt 信号槽。设备扫描、连接、命令、采集、监测、布局和日志由应用服务提供，页面不直接访问 PyVISA、PySerial 或 SDK。侧栏标注真实设备或模拟演示；模式修改只在系统设置页完成。

## 2. 一级导航和顶部子菜单

左侧一级导航保持：

1. 设备管理
2. 数据采集
3. 实时监测
4. 数据处理
5. 操作日志
6. 系统设置

设备管理和实时监测均提供总览及十二类设备入口。设置页提供模式选择和数据目录说明；数据采集、数据处理、操作日志目前保留导航说明，记录入口在监测类型页，审计文件在运行根目录 logs。完整采集历史/处理/日志工作台为后续范围。

## 3. 模式和状态

“软件设置”页提供模式选择，侧栏底部只读显示。切换不重建窗口、不自动连接或写入；记录/控制期间锁定，纯监测保留后台任务。当前模式不适用设备仍在总览显示，但不能绑定或发起控制/采集。电子学与光学的布局、草稿、槽位和数据隔离。

## 4. 设备管理总览

总览以分类卡片呈现设备池，卡片显示类别、描述、可见数、在线数、未连接、异常和已绑定数量。信号源、电源、示波器、频谱仪、温控设备五类始终保留；其他类别按库存出现，光学模式补充光学测量入口。电子学/光学模式只改变适用性与控制/绑定入口，不隐藏已有库存。

顶部分类标签进入各设备类型的控制页。点击卡片打开右侧设备池，筛选并选择设备后查看详情，可手动收起。首页不展示整页设备表。卡片在宽窗口三列，缩窄后两列或一列；监测总览保留适用于多路数据的响应式卡片。

设备抽屉提供厂家/型号/序列号/地址、通信参数、连接/断开/重连、修改名称和重新分配功能槽位。打开详情本身不访问仪器。功能块始终提供 `请选择设备`，它表示未绑定。运行中的任务禁止更换槽位。

## 5. 视觉规范

- 黑曜石背景、银白文字、琥珀橙重点数字和低饱和灰色辅助文字，使用自定义 QSS 统一间距、字号和状态标签。
- 分类卡片沿用历史稿的细边框、琥珀顶边、圆角及数字层级；导航、表单与按钮保持同一配色，不使用霓虹渐变。
- 正常为绿色，警告为黄色，异常为红色，未连接为灰色。
- 重要数字和设备状态使用高对比度文本；表格、告警和操作结果提供清晰的键盘焦点。
- pyqtgraph 用于波形、频谱和高密度趋势图；不在第一版同时引入其他图表库。
- 不直接采用 GPL 主题组件；需要 Fluent 感觉时，用自有 QSS 和 Qt Widgets 组合实现。
- 卡片以琥珀色突出在线数量；连接状态使用绿色、黄色、红色和灰色语义色。运行时只加载 `ui/styles/card_workspace.qss`，新增页面沿用此主题。
- UI 设计参考 Tabler 的卡片和分段控件、Grafana 的状态表达、shadcn/ui 的控件状态，但不引入其运行时依赖。

## 6. 当前实施边界

共用窗口位于 `ui/real_window.py`，分类卡片与响应式网格在 `ui/widgets/category_cards.py`，服务桥接在 `ui/controller.py`。参数表单位于 `ui/pages/device_control/`，监测类型页、绘图和响应式总览位于 `ui/pages/monitoring/`；展示标签/分组在 `application/controls.py`，厂家命令只在 instruments 内。

MonitoringService 调度原会话 worker，Qt 只消费快照与批次。宽屏类型页使用图形加参数侧栏，窄屏改为上下排列；监测总览按 360 逻辑像素目标宽度、16 间距计算列数，不保存列数。真实通信、SQLite、CSV/NPZ 已接通；HDF5 和后续完整工作台未实现。旧 `ui/main_window.py` 仅保留历史设计回归，不作为演示入口。
