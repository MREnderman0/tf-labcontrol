# Python 前端结构（0.3.0）

`run.bat`、`python -m lab_control` 和 `lab-control` 调用同一正式启动函数。内部测试和预览注入隔离的 Mock ApplicationRuntime，共用应用窗口、分类控制和监测组件，不注册演示启动器。扫描细节见[设备发现与总览](../requirements/device-discovery-and-overview.md)，参数和任务细节见[设备管理](../requirements/device-management.md)与[实时监测](../requirements/realtime-monitoring.md)。数据处理、完整实验编排和阈值告警尚未实现。

## 1. 目标形态

前端使用 PySide6 + Qt Widgets，固定为[用户确认的历史分类卡片版](../../direction-approved.md)：左侧一级导航、顶部分类标签、侧栏底部模式与真实/演示标识。扫描入口位于顶栏；首页采用三列分类卡片，窄窗口减少列数。

PySide6 只负责界面和 Qt 信号槽。设备扫描、连接、命令、采集、监测、布局和日志由应用服务提供，页面不直接访问 PyVISA、PySerial 或 SDK。侧栏标注真实设备或模拟演示；模式修改只在系统设置页完成。

## 2. 一级导航和顶部子菜单

左侧一级导航保持：

1. 设备管理
2. 实时监测
3. 数据处理
4. 操作日志
5. 系统设置

设备管理和实时监测都提供总览；顶部设备类别标签只显示当前存在已连接会话的类别，类别最后一台设备断开后自动返回总览。设备管理提供可控制设备入口，实时监测总览按类别显示当前已连接、可记录的设备卡片，卡片显示功能槽位、采样间隔、是否参与采样和运行状态，不承载实时图表；记录中及二进制收尾期间显示红色描边。勾选状态按模式和槽位持久化，右上角统一开始或停止采样。光功率计只在实时监测出现，设备管理仍保留“光学测量”分类卡片和连接流程，旧控制入口自动跳转监测页。设置页提供模式选择和数据目录说明，审计文件在运行根目录 logs。

## 3. 模式和状态

正式入口与 Mock 预览统一使用 `general` 工作区，不提供电子学／光学选择或模式标识。设备控制、监测与绑定依据型号能力、范围、会话和任务锁；草稿、槽位和采集偏好按通用工作区及设备保存。旧标识仅作为接口和历史元数据兼容值，不限制设备类别。

## 4. 设备管理总览

总览以分类卡片呈现设备池，卡片显示类别、描述、可见数、在线数、未连接、异常和已绑定数量。信号源、电源、示波器、频谱仪、温控设备五类始终保留；其他类别按库存出现。所有设备使用同一工作区，不因电子学／光学分类限制控制或绑定入口。

顶部分类标签进入各设备类型页；光功率计标签只在实时监测显示。点击卡片打开总览内的设备池对话框，筛选并选择设备后查看详情，可手动关闭。首页不展示整页设备表。卡片在宽窗口三列，缩窄后两列或一列；监测总览保留适用于批量采样控制的响应式设备卡片，曲线和读数只在设备类型页显示。

设备抽屉提供厂家/型号/序列号/地址、通信参数、连接/断开/重连、修改名称和重新分配功能槽位。打开详情本身不访问仪器。功能块始终提供 `请选择设备`，它表示未绑定。运行中的任务禁止更换槽位。

## 5. 视觉规范

- 黑曜石背景、银白文字、琥珀橙重点数字和低饱和灰色辅助文字，使用自定义 QSS 统一间距、字号和状态标签。
- 分类卡片沿用历史稿的细边框、琥珀顶边、圆角及数字层级；导航、表单与按钮保持同一配色，不使用霓虹渐变。
- 正常为绿色，警告为黄色，异常为红色，未连接为灰色。
- 重要数字和设备状态使用高对比度文本；表格、告警和操作结果提供清晰的键盘焦点。
- pyqtgraph 用于波形、频谱和高密度趋势图；不在第一版同时引入其他图表库。
- 不直接采用 GPL 主题组件；需要 Fluent 感觉时，用自有 QSS 和 Qt Widgets 组合实现。
- 卡片以琥珀色突出在线数量；连接状态使用绿色、黄色、红色和灰色语义色。运行时只加载 `ui/styles/card_workspace.qss`，新增页面沿用此主题。
- UI 设计参考 Tabler 的卡片和分段控件、Grafana 的状态表达、shadcn/ui 的控件状态，但不引入其运行时依赖。

## 6. 当前实施边界

共用窗口位于 `ui/real_window.py`，分类卡片与响应式网格在 `ui/widgets/category_cards.py`，服务桥接在 `ui/controller.py`。参数表单位于 `ui/pages/device_control/`，监测类型页、绘图和响应式总览位于 `ui/pages/monitoring/`；展示标签/分组在 `application/controls.py`，厂家命令只在 instruments 内。

MonitoringService 调度原会话 worker，Qt 只消费快照与批次。宽屏类型页使用图形加参数侧栏，窄屏改为上下排列；监测总览按 360 逻辑像素目标宽度、16 间距计算列数，不保存列数。光功率计使用独立的全通道工作台：复选框状态同时驱动曲线、实时卡片和采集请求；运行中通过原子请求版本替换刷新通道，过期在途帧不显示也不写盘，空集合保持监测任务但暂停采集。开始监测和开始记录分离，记录仍使用 `record_interval=None` 逐帧提交，显示层只做 W/dBm 换算，右侧参数卡片只保留整机波长。真实通信、SQLite、CSV/NPZ 已接通；HDF5 和后续完整工作台未实现。旧 `ui/main_window.py` 仅保留历史设计回归，不作为演示入口。
