# 频谱仪紧凑监测界面

## 操作与入口

保留总览频谱仪卡片和设备连接；设备管理不再提供频谱仪标签，旧控制入口转向实时监测。
左侧曲线、右侧四行参数共用真实与 Mock 组件。起止频率与中心/扫宽在编辑完成后联动；一个应用按钮仅提交变化项。
衰减、RBW、VBW 的自动开关属于草稿，点击应用后才执行；离散档位按型号提供。范围与来源常驻，非法数值静默恢复。
采集为被动轨迹读取，不隐含 INIT；仪器已有扫描模式仍由仪器控制。记录、导出和监测总览入口在曲线工具菜单。

Auto 是独立仪器操作，有未应用修改时确认一次，成功读回后替换草稿。未核实 Auto 的型号保持按钮禁用。
分组写入暂停本设备自动读取、串行逐项核对；失败停止并保留剩余草稿。正常完成后沿用此前监测/记录状态。

## 软件标记

标记定义按设备和工作模式保存，增删改均不写仪器。双击虚线、横轴标签或列表项可编辑。
固定标记从最近采样点取幅度；寻峰使用完整有效轨迹，在固定中心 ± 搜索半宽内找最高值，等高时取最靠近中心者。
默认半宽为创建时扫宽的 5%，不随峰移动。范围外保留定义，无数据不伪造数值，时间轴暂停频率标记。
标记跟踪结果只保留内存，缩放和采样点下采样不会改变算法输入。停止监测时显示最后一帧及其时间。

## 软件验证与边界

回归包含频率联动和不相交频段的写入顺序、离散带宽、单位保持、NaN 恢复、Auto 草稿确认/失败、部分失败停止、双设备草稿隔离、标记双击、峰值及异常数据。
20 台混合设备（12 频谱仪、4 信号源、4 电源）覆盖慢读、故障、监测及分组占用：每设备最大通信并发 1，自动读取最大并发 4，每批最多 4 项，自动参数写入 0；结果见性能记录。
采集返回的型号读取快照复用会话缓存，旧配置版本曲线丢弃；没有新建轮询线程。
型号 Auto 使用严格协议夹具覆盖完成等待、错误响应、超时及读回失败，失败不重发。

本轮仅软件和协议夹具验证，未执行实机参数写入、Auto、输出或物理精度验收。其他参数保留底层和 CLI 能力。
