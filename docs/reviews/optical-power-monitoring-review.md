# 光功率计全通道实时监测验收

本批次覆盖 Joinwit JW8105 Mock 能力、光功率计实时页面和共享连续记录入口。设备管理保留“光学测量”分类卡片，光功率计旧控制入口转入实时监测；页面不创建按通道切换的设备管理子页。

| 检查项 | 结果 |
| --- | --- |
| 8 个通道默认出现并选中 | `tests/integration/test_optical_power_workspace.py` 通过 |
| 复选框过滤采集请求、曲线和读数卡片 | 通过；变更通道只丢弃在途帧并刷新请求，监测任务保持运行 |
| 0.5～60 秒采样间隔 | 共享 `MonitoringTiming` 固定间隔控件，通过 |
| 开始监测与开始记录分离 | 开始监测不创建记录，开始记录使用 `record_interval=None` 逐帧提交 |
| 停止记录/监测排空二进制记录 | 通过；CSV 转换保留后台执行 |
| dBm 显示换算与原始单位 | 显示转换为 W，原始帧仍保存 dBm，通过 |
| 1280×760、1440×900 与窄布局 | 由 `scripts/review_optical_power_meter.py` 生成离屏截图 |

本轮仅使用隔离 Mock，未声称真实设备通信、功率精度或物理输出验收通过。原始批次与运行目录不提交到源码。
