## 扫描与连接边界补测

扫描中的枚举与探测间隙均拒绝新连接，设备池给出等待提示；实际发现但探测失败的设备保留行、选择和错误，下一次未发现或应用重启后不沿用旧的在线证据。测试同时覆盖 DHCP 地址复用时重新核验身份，以及扫描收尾不得覆盖较新的连接证据。

Mock 软件回归 65 项通过，Ruff 与 Mypy 通过；[异常界面截图](../../design/reviews/dsa815/scan-failure-1440x900.png)使用隔离 Mock 和模拟工作区尺寸。此次硬件复核仍发现间歇性 LAN 发现/打开失败，不能用单次成功声称链路已稳定；实际诊断、网络配置与成功/失败批次仅保存在正式运行目录。全项目回归另有窗口尺寸、电源页面接口及同步时序失败，详见该次运行目录日志，不将其计为全部通过。

后续只读对照保持 DHCP 和电脑网络配置不变：同一 VISA 会话连续 60 秒身份读取通过，但第 3 次重新建连失败。独立 RPC 诊断出现一次自动选择其他网卡源地址并超时；随后自动选择与绑定有线地址的各 8 个样本均通过。该现象是待复核线索，尚不能证明 VISA 失败的根因或归因于 DHCP；诊断用绑定地址的 socket 未引入产品传输层，也未据此自动修改网络、重试连接或要求所有设备改网段。

再次复现后，通过 Windows 只读端点表捕捉到失败 VISA 进程的实际 TCP 连接：源地址属于 Wi-Fi，目标为选定频谱仪的 RPC 端口，持续停留在 SYN_SENT，约 15 秒后打开失败。独立普通 TCP 对照亦超时，显式绑定有线源地址的 RPC NULL 请求成功。这确认了失败连接使用不合适的本地地址；尚未证明 DHCP 租约变化，也未修改电脑路由或仪器地址。具体端点和时间仅存运行目录。

探测错误分类同时修正：连接失败、超时及未分类异常不再显示为“驱动异常”；仅明确的 `driver_missing` 显示“运行库不可用”，旧的未分类记录显示待核对。VISA 传输保留运行库错误代码，发现结果和审计记录保存分类，不增加重试或额外探测。相关传输、发现和 Qt 回归 43 项通过，Ruff、Mypy 通过。

该修正后的全项目软件回归为 1103 项通过、1 项跳过，文档检查无错误；此前记录的全项目失败保留为历史结果。用户随后手工改为固定地址的实机复核独立留档，不能由这些软件测试推断网络已经恢复。

固定地址的真实身份验证后又发现历史地址合并问题：两次连接共用了 `connected` 标签，被当成同一批次的多主机身份冲突。已将重复会话标签与真正的扫描批次区分；对旧误判仅在新身份读回匹配后解除，不删除旧地址历史，不放宽真实多主机冲突或活动身份租约。相关回归包含跨地址连接、历史误判修复、未重新核验仍禁止连接、真实扫描冲突继续阻止连接。

最新全项目回归 1108 项通过、1 项跳过；一次静默运行停滞后中断，随后启用详细日志和线程超时诊断的完整运行通过，两份日志均留档。实机已在用户保存固定地址后完成 3 轮真实 Qt 扫描/连接/断开、60 秒连续身份读取及有线源地址检查；保存前未响应和旧地址误判的批次保留。这一结果限定为该资产当前配置的连接复测，不能推广为任意 DHCP 环境通过或物理精度验收。

## 后续直连 DHCP 复测（2026-09-24）

本机专用以太网部署 DHCP 后，用户在面板启用 DHCP/AutoIP 并拔插网线。仪器取得保留地址，真实 Qt 完成三轮扫描、连接、网络状态读回及断开；150 秒连续身份读取跨过一次续租，全部通过。登录启动项配置后再次连接和 60 秒只读复核通过，原资产 UUID 保留。最终全项目回归 1140 项通过、1 项跳过，Ruff、Mypy（136 源文件）和 114 份文档检查通过。真实地址、身份、日志和各失败批次仅存运行目录。

本轮另修正后台只读任务期间设备池断开按钮短暂禁用的问题：点击后在当前读取结束时释放会话，控制/采集占用仍被拒绝。早期未取得租约、测试脚本状态判定及 GUI 占用等记录均保留，不改写为通过。

结论限于当前电脑与单台已选设备的 DHCP 发现、连接、续租和拔插。新电脑、换物理网卡、多设备地址分配以及电脑重启后的登录过程尚未实测；当前 DHCP 动态池关闭，仅使用本次资产保留地址。自动发现新网口不等于 DHCP 服务自动迁移，物理测量精度未验收。通用行为及边界见[实验网发现](../architecture/lan-discovery.md)。
