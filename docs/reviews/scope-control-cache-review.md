# 示波器粗细调、参数缓存与 Auto 验证

日期：2026-09-27。全部使用离线合成 SCPI、正式 Qt 页面和公共调度服务；不连接真实仪器、不修改仪器状态。历史实机控制结论不扩展到本次 Auto 或局部缓存更新。

## 修改与一致性

右栏底部固定微调开关及 Auto 按钮。偏移和触发电平普通步长 0.1 格、微调 0.01 格，不小于已知有效粒度；微调采用相对拖动，最多普通灵敏度的十分之一且不超过每逻辑像素 0.01 格。不足一步的移动累计，非标准原值在实际操作前保持；方向键一步、翻页十步、松手一次提交。偏好按设备和模式保存，记录及二进制排空锁定。

按后续要求增加水平和垂直缩放/偏移的即时估算预览：16 ms 合并显示更新，垂直用场景仿射变换重用已有曲线和降采样缓存，水平更新固定网格视窗，不复制完整样本。偏移方向由可选通用显示元数据提供；公共绘图无厂家分支。估算状态明确标注，保存仍引用原始帧；提交后等待对应配置版本的有效帧，失败恢复真实刻度。连续手势不会被上一设置的新帧误清除。

可选 `ControlUpdate` 将型号已核验的修改项及关联读回发布到新配置版本，无关字段保留值、原始读回时间及接收时间，来源 `control_cache`。型号负责参数/CVAR 依赖，Qt 用排队完成信号推进事务，不逐批等待 100 ms 轮询。失败或不确定写入不发布成功覆盖，不自动重发。

DHO924 局部控制后的首帧保留 PRE 对新设置的对应校验及 DATA 前后 PRE 一致性。9404M 保留无关 WAVEDESC 指纹，首帧仅再次核对受影响参数，再固定新指纹；稳定帧仍每通道一次 `WF? ALL`。每帧用自身描述解码 WORD，显示及保存数组不依赖缓存缩放。新批次、Auto、主动刷新、未知依赖、缓存缺失及异常完整核对，显式 full/完整存储契约不变。

Auto 使用 DHO924 `:AUToset`（先检查原生启用状态）及 9404M 不带 FIND 的 `C1:ASET`。单次写入后有界同步、完整刷新，按新通道恢复此前软件监测；原本未运行或全关通道不启动。禁用、超时及空输入行为只做 Mock 验证，不声称取得新触发。
