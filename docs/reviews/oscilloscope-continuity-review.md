# 示波器调参连续性、点数与有界接收

日期：2026-09-26。沿用分类卡片、左图右控和正式深色琥珀主题。本轮软件验证与空输入短时实机复核分开报告；物理精度、USB/VICP、高级触发及全量长时性能不在本轮验收内。

## 改动与范围

水平区增加仪器最大采集长度输入，旁边常驻 CVAR 与软件 1,000～10,000,000 的交集，原超范围值仍如实显示。实际有效点数另列。滑块使用固定合法端点，正常读回不重新居中；偏移和电平按完整范围映射，键盘以型号粒度微调。拖动只预览，松手一次提交，键盘操作合并提交。记录及二进制排空继续锁定全部仪器控件。

示波器和频谱仪均从“曲线工具 → 采集节奏”展开设置，默认收起，保留最快/自定义 0.5～60 秒、持久化及始终可见的实际帧间隔。正式主题截图位于 [示波器页面](../../design/reviews/oscilloscope/page-1440x900-1.png)、[150% DPI 页面](../../design/reviews/oscilloscope/page-1280x760-1.5.png)、[记录锁定](../../design/reviews/oscilloscope/recording-locked-1.png)、[等待新帧](../../design/reviews/oscilloscope/waiting-1.png)及[频谱仪页面](../../design/reviews/spectrum/spectrum-1280x760.png)。提交的图片只含 Mock 数据。

9404M 在连接、主动刷新和关联设置改变时读取 CVAR 范围/粒度及实际内存配置；稳定帧不增加查询。设置后单次有界 OPC 同步，量化仅凭明确粒度/档位及 CVAR 请求/适配值证据接受，保留真实读回。正常控制事务结束自动续采，旧图保持旧刻度；不确定写入不重放。

VISA INSTR 新增可选有界二进制读取：64 字节头部先核对声明长度，再按上限接收，截断、超限与尾随分别报告长度证据。丢失消息边界后关闭连接，显式重连；采集前已知超预算则不发送波形查询，保留连接供调整设置。WORD 精度、完整有效数组、每帧描述校验及保存语义保持不变。其他型号默认接口兼容。

## 实机事实与限制

用户确认四通道未接线并断开正式程序。先检查真实运行目录和设备锁；AppData 重定向的预检拒绝访问并留档。后续从原生用户环境进入正式型号工厂/会话，每次核对完整身份，不终止其他进程、不抢锁。真实资产标识、原始通信、波形、初末快照、恢复差异和各批次摘要仅存运行目录。

| 项目 | 本轮结论 |
| --- | --- |
| 连接、只读与重连 | 完整身份及参数读取通过，批次执行三次关闭重连 |
| 垂直偏移 | 60 μV 请求读回 100 μV，粒度 100 μV；请求/适配值证据一致，监测续采 |
| 水平偏移 | 1.73 μs 请求读回 1.74 μs，粒度 20 ns；证据一致，监测续采 |
| 时基范围 | 当前配置 CVAR 上限 20 ms/格；100 ms/格不能作为普通量化放行 |
| 最大点数 | MSIZ 1000/2500 写入及读回成功；实收仍为 5002 点，不能宣称最大长度已限制采样 |
| 大回包保护 | 长时基下声明 127,880,982 字节，仅接收 64 字节后拒绝并关闭；后续测试中止 |

| 保存与后续组合 | 本轮未重复实机长时记录；有界队列、显示帧保存和排空锁通过软件回归。长短时基完整连续组合未全部通过，不以局部通过替代 |

所有失败、受阻和独立恢复原始批次均保留。已更新运行目录索引、资产状态及离线总览；历史缺项继续列待核对，不能提升为整机验收。
