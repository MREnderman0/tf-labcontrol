# 自动设置后的监测一致性与间隔调节验收

日期：2026-09-25。使用隔离 Mock、真实 Qt 页面及现有运行日志；本轮未打开真实仪器、未重新执行实机自动设置、未修改网络配置。

## 问题与修复

历史日志显示自动设置已经成功，随后曲线读取因前后配置不同抛出 `configuration_changed`；原公共会话把该帧错误升级为连接异常并暂停监测。旧日志没有变化字段，不能据此确定具体哪个参数发生变化。

型号包现在先验证完整轨迹回包，再报告发生变化的字段及前后值。公共会话将此类帧丢弃并保留可用连接；连续监测按正常间隔获取下一帧，连续三次仍变化则暂停，单次读取不重试。超时、断线和损坏回包仍停止任务。设置命令不自动重放。

旧调度在读取完成后额外等待完整刷新间隔。现在按相邻请求开始时间调度，一台设备仍只有一个读取在途，慢读取不堆积任务。刷新和保存分别可调；慢写盘期间曲线继续更新，自动保存最多一项在途。设置偏好按设备与模式保存，仅编辑不会启动采集、记录或写入仪器。频谱仪设备池仅保留一个“实时监测”入口。
