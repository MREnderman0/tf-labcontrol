## 已验证行为

- 设备池居中于总览内容区，最大 960×640 逻辑像素，四周至少 24 像素留白，使用深色半透明遮罩、圆角和阴影。宽度不足 760 像素时从左右布局切换为上下布局；长字段换行，正文可纵向滚动，没有横向滚动。
- 左侧设备卡片显示名称、型号和状态；右侧分为设备身份、连接信息、功能槽位和发现记录。连接／断开、设备控制、实时监测固定在底部，“更多”保留其他操作，采集中单独显示停止按钮；原有启用限制继续生效。
- 上方分类页签、左侧模块和程序内导航均关闭设备池，返回总览不自动重开；空白处、Esc 和关闭按钮可关闭。下拉菜单、“更多”和真实重命名对话框独立关闭，池内点击不误关闭。遮罩不会点击穿透；打开进入弹窗焦点，关闭返回分类入口。
- 扫描结束、周期刷新、选择变化与缩放不会打开已关闭弹窗；点击露出的另一分类卡片直接切换。刷新保持选中设备和滚动位置，不增加设备查询。
- 默认范围仅统计当前证据/有效会话；未接入的历史 SMA100B 在历史范围显示探测失败，名称、身份、槽位与设备 ID 保留。
- 配置与枚举同地址保留各来源且只探测一次；未经验证的网络地址不算发现；别名中仍有当前证据时去重计数。
- 来源失败和扫描取消归为未确认，不能报告拔出；失效会话缓存不提升存在性；活动会话保护沿用既有回归。
