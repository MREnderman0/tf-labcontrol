# 示波器短时基显示修复与工作区整理

日期：2026-09-25。使用隔离 Mock、正式 Qt 界面及已有实机波形离线回放；本轮不连接仪器、不修改仪器设置，不增加物理精度或接口实测结论。

## 原因与当前行为

微秒波形在默认秒级视图下启用峰值降采样，降采样分组大于整帧点数，得到零个显示点；自动缩放随后也没有显示点可供计算。历史波形离线解析得到 5002 个有效点、约 ±5 微秒坐标；旧路径显示点数为零。新增回归检查实际绘图点与路径，避免只验证原始数组存在。

频谱与示波器共用 TraceView，在降采样前使用完整数组进行一次性适配。稳定帧保留手动范围，示波器稳定帧不重复求全数组幅度范围；配置、设备、会话、通道及单位变化重新适配，记录元数据和正常水平原点抖动不触发适配。页面和总览提供“适应曲线”，按原数组恢复。单点保留时间坐标并显示点标记，恒值有非零范围。

“请求点数”与实收点数分别显示，完整波形提示来自已有批次元数据。保存当前帧仍固定已显示的不可变数组，不访问仪器；连续记录、缓存与协议校验沿用公共实现。本次没有新增运行依赖。

## 验证

自动化覆盖纳秒/微秒/毫秒首帧、四通道、恒值、单点、配置和单位变化、手动缩放保持、隐藏后重显、重连、无效帧、恢复空显示、页面/总览入口及保存数组一致性。型号缓存和记录回归随全量测试执行。
