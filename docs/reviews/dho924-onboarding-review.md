# DHO924 接入与空输入功能验证

日期：2026-09-27。本轮接入精确型号 RIGOL DHO924，适配标识 `rigol.dho924`，不扩展到 DHO924S 或其他 DHO 型号。[型号维护源](../../src/lab_control/instruments/devices/rigol_dho924/README.md)包含范围、协议、限制和硬件入口；本页记录本轮验证条件与结果。

## 实现范围

新增独立型号包，经唯一目录注册，使用现有 PyVISA 与 VISA 组件。支持四个模拟通道及公共示波器控制页面。点数输入显示离散存储档位，采样率作为只读关联量；不套用 LeCroy 的固定采样率公式。关闭通道时禁止垂直编辑，参数写入后执行有界完成同步和实际读回。监测中调参等待在途读取，完成后自动续采；记录及排空期间锁定控制。

默认监测与逐帧记录读取每通道完整 1,000 点屏幕波形；“曲线工具 → 读取完整存储波形”是独立操作，排队、备份、停止、完整读取并恢复原运行状态。记录期间禁用，公共会话同样保护直接 API 调用；完整读取排队及执行期间不能开启记录。单次触发等待期间拒绝打断；失败报告实际状态，不重发不确定写入。保存当前帧只保存已有数组，不访问仪器。

公共层新增可选波形范围和 VISA SOCKET 有界二进制读取。接收正文前按声明长度检查预算，校验正文与结束符，边界不确定即关闭会话。型号层用帧自身 preamble 解码小端无符号 WORD，检查长度、时间轴、有限值及描述与快照的一致性；稳定帧不插入独立参数轮询。显示映射不改变保存数组。

## 实机结果

用户确认四通道未接线。通过正式运行目录、真实设备锁和序列号绑定访问唯一目标，未访问其他资产或修改网络。AppData 重定向副本不作为正式库存或锁；本轮从原生用户进程执行正式会话。所有原始结果、通信、波形、快照、恢复差异和摘要保存在运行目录，源码不包含真实地址、序列号或 MAC。

| 项目 | 已验证结果及边界 |
| --- | --- |
| 连接与重连 | VISA SOCKET 身份、全部设置只读备份及三次关闭重连通过；固件 00.01.05 |
| 参数 | 28 个保守用例通过，含四通道隔离、显示、档位、偏移、耦合、探头、时基、位置、存储及模拟边沿触发 |
| 采集状态 | AUTO/NORM/STOP 验证通过；空输入 SINGLE 只确认等待状态，不标为采集完成 |
| WORD 契约 | 停止状态逐点对照 ASCII，正偏移码值越过 32767，确认小端无符号解释；误差界限来自实际返回小数精度 |
| 屏幕与完整存储 | 四通道分别读取 1,000 点屏幕及 10,000 点完整存储；读取时各通道顺序执行，不宣称同次触发同步 |
| 监测 | 最终约 60 秒批次取得 87 帧，含调参续采和完整存储读取后恢复；保存计时，不承诺触发率或帧率 |
| 保存 | 单帧导出通过；最终约 60 秒记录接收、提交、转换均为 113 帧，452,000 个样本二进制/CSV 逐点一致，无待排空项，参数锁释放 |
| 恢复 | 完整功能批次及最终采集批次初末快照差异均为零，恢复原 AUTO 和通道状态，关闭本任务会话 |
| 交付配置 | 保存正式程序可使用的显式 Socket 资源和预期序列号，保留原有其他设备配置，不自动切换协议 |

早期发现的 ASCII 非 IEEE 块格式、preamble 小数精度、单独完成查询返回 0、关闭通道忽略垂直设置及运行状态延迟，分别保留失败批次并增加回归。当前实现采用 `*OPC` 标记后有界查询，严格核对实际设置；没有通过放宽全局容差或重发设置掩盖失败。短时复核因控制操作占用采集时间未达到最低帧数的批次亦保留，后续按完整 60 秒重新验证。

USB 未测试；VXI-11 打开失败且原因未确认。物理幅度、频率、带宽精度，数字/数学/分段和高级分析不在验收范围。点数设置实测 1k/100k、完整读取实测 10k；最大 10M 及所有档位组合未做极限实测。空输入功能通过不等于整机精度验收。
