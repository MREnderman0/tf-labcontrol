## 复审发现

| 问题 | 修复及回归要求 |
| --- | --- |
| GPD-4303S 的旧公共标量采集分支迁移后，型号适配器未实现新的分发入口，实际采集会返回“不支持” | 在本型号中接入通用电源读数函数；通过正式注册工厂与协议 Mock 核对读数、单位及命令顺序；增加所有声明采集能力的 SCPI 型号分发契约检查。 |
| Runtime 上下文主体抛错时，关闭错误可能覆盖主异常 | 保留原异常对象，将关闭错误及其附加信息记录为 notes；没有主异常时仍抛出关闭错误。 |
| 自动采集设置将开始前审计改为尽力写入，审计失败后仍可能执行设备设置 | 恢复严格的开始前审计，并放入收尾保护范围；审计失败必须阻止设置、完成 Future 并释放控制计数。 |
| Controller 在读取快照期间完成的任务可能立即触发回调，使回调读到任务完成前的缓存 | 先确定本次交付任务，再读取快照和交付；快照期间完成的任务由后续唤醒交付，保持每次轮询只读取一次快照。 |
| 实机指南、监测要求和 SDG2082X 型号说明仍有旧工作区、GUI 高级入口或记录格式描述 | 对照实现修正现行正文；区分单帧与连续记录、标量历史缓存及二进制/CSV 收尾；型号派生页由生成器更新，旧锚点与历史结论保留。 |
| 12 个迁移型号卡片的新章节未保留原有的十个章节锚点 | 在包内维护源补齐兼容锚点并重新生成卡片；将全部变更 Markdown 与原提交逐项比较，检查旧锚点是否丢失。 |
| 无 Git 检查的说明未区分完整源码与精简源码发行包 | 明确检查器仍报告缺失文件，完整文档验收须使用完整源码仓库；不把缺少历史图片资料的 sdist 声称为完整文档包。 |
