# 示波器采样率只读展示与触发布局验收

日期：2026-09-28。使用合成 SCPI、正式 Qt 页面及深色琥珀主题；本轮没有连接或改变真实仪器。

## 行为与数据来源

右侧顺序为水平、CH1～CH4、触发；原触发源、电平与齿轮完整移至最后一张卡片。微调和 Auto 保留固定底栏。水平卡片的采集点数下方用文字显示仪器采样率，不加输入框或独立卡片。

两型号共用 `CapabilitySnapshot.details.memory.sample_rate`，显示 Sa/s、kSa/s、MSa/s、GSa/s；不在 UI 判断型号，不查询设备，不从屏幕波形间隔推算。调参期间保留最近确认值，失效快照弱化并显示“待更新”；非法数值或断开后显示“—”，重连/切换设备不继承旧会话缓存。记录及排空锁不影响只读查看。未新增公开 API、仪器命令、运行依赖或部署代码。
