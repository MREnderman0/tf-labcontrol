# 文档与离线实机台账整理验收（2026-09-24）

## 本批范围

整理文档结构、导航、模板和生成检查；为四个独立信号源模块增加离线记录转换及新批次摘要。只读取既有实机记录，没有加载 VISA 运行库、连接设备、修改仪器、库存或默认配置。

目录及旧入口对应见[文档维护与迁移清单](../development/documentation.md)；今后接设备从[新设备流程](../testing/onboarding.md)开始。源码不包含真实序列号、地址或原始通信。

## 历史记录导入

- 正式程序运行目录和已确认的旧桌面重定向目录分别作为来源，不把合并视图当成同一份历史。
- 纳入 AFG31252、SDG2082X、SMA100B、DG5504 Pro 共 53 个批次，包括失败、受阻及空批次。
- 导入前后核对 603 个原始文件的 SHA-256：无改变，无新增原始文件；人工 connection-status.md、原 index.md、快照和波形备份保持。
- 41 个批次列为资料待核对，原因包括缺少版本/范围等字段、未知结果枚举或未完成的批次；这不是 41 次设备测试失败。
- 总览及每条待核对原因位于正式运行目录 `hardware-tests/overview/`；`import-audit.json` 保存本次来源、结果和原始文件哈希。具体设备身份与路径仅留运行目录。

## 使用与维护

按[离线台账命令](../testing/records.md)导入或重建。派生文件可重建，原始证据不能被覆盖；摘要生成失败不打断仪器恢复。删除型号会使未知格式保留为待核对索引，不删除历史资产。
