# 光谱仪

## 1. 型号和可信度

状态：待补信息。缺厂家、完整型号、接口和光谱数据格式。不注册真实型号适配器。

## 2. 电脑连接

待确认背板接口与厂家手册。USB 插头、COM 号或 IP 地址不能证明协议，不能默认使用 SCPI/Modbus。

## 3. Windows 驱动

待厂家提供驱动或 SDK 与位数/版本。未知设备可在总览登记资源和系统描述。

## 4. 枚举方式

系统/VISA 可登记候选；未知串口不开启、不轮询波特率，不遍历发送身份或控制命令。

## 5. 命令依据

尚无足够官方依据。取得手册、协议版本、帧格式/寄存器定义后再添加真实命令。

## 6. 类别接口

已有模拟 ID：sim.optical_spectrometer，仅 transport=mock 可用；模拟范围是测试数据，不代表实机安全范围。

## 7. 控制和采集

真实控制/采集返回 unsupported。待确认数据单位、通道、时间戳、状态/告警和异常值定义。

## 8. 安全和断连

不自动连接或启用输出。真实适配器完成前不能绕过未知设备边界下发原始命令。

## 9. Python 落点

未来实现放入所属 instruments 类别模块，并注册精确身份；现有类别模拟在 demo/instrument.py，UnknownDeviceAdapter 在 instruments/base.py。

## 10. 测试和下一步

收集铭牌、背板、序列号、固件、Windows 设备信息、官方手册和一组无危险操作的请求/响应。补协议夹具、字段和错误测试后，按[实机指南](../../hardware-testing.md)验收；不得以模拟成功标记真实可控。
