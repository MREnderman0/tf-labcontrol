# 电源

电源统一实现 `PowerSupply` 能力：通道、电压、电流、测量值、保护状态和输出启停。输出默认关闭，任何启停和高风险设定都要经过范围检查、二次确认和审计。

| 型号 | 接入路线 | 状态 | 文档 |
| --- | --- | --- | --- |
| GPD-4303S | USB 驱动/厂商软件/LabVIEW | 资料确认，待实机验证 | [GPD-4303S](gpd-4303s.md) |
| Keithley 2231A | 2231A-001 USB 适配器，VISA/串口 | 资料确认，待实机验证 | [2231A](keithley-2231a.md) |
| PSW160（厂家未确认） | 完整型号和接口待补 | 待补信息 | [PSW160](psw160.md) |
| SPD4306X | USB/LAN/VISA/SCPI | 资料确认，待实机验证 | [SPD4306X](spd4306x.md) |
| IT6322 | USB/RS-232/GPIB，选件依型号 | 资料确认，待实机验证 | [IT6322](it6322.md) |

电源采集必须同时保存设定值、测量值、通道、输出状态、保护状态、时间戳和质量标记。
