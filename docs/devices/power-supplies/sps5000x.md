# SIGLENT SPS5000X 系列

注册 ID 为 `siglent.sps5000x`。通过 `*IDN?` 核验厂家、完整子型号和序列号后加载实际通道和额定范围。铭牌系列名 `SPS5000X` 仅用于选适配器，连接前的能力表以 CH1 占位。

## 能力与协议

在「实时监测 → 电源」中按通道设置和读回电压、电流限值，监测及记录实测电压和电流。兼容层也提供逐通道的实测功率查询。整机输出开关使用 `OUTPUT`，需要显式确认。各通道的使能保留面板上的设置。

- [SPS5000X 用户手册 E02B](https://int.siglent.com/u_file/download/22_06_28/SPS5000X_Usermanual_E02B.pdf)，Remote Control 章第 78–100 页，涵盖接口、身份、参数、测量、输出和模式查询。
- [SPS5000X 数据手册 EN01H](https://int.siglent.com/u_file/download/25_02_19/SPS5000X_DataSheet_EN01H.pdf)，用于核对完整子型号、通道数、单通道额定范围与 1 mV / 1 mA 设置分辨率。

## 连接与驱动

| 接口 | 接入方式 |
| --- | --- |
| 后面板 USB Device | 使用 PyVISA 枚举的 `USB…::INSTR` 资源。 |
| LAN VXI-11 | 使用 PyVISA 的 `TCPIP0::<设备地址>::inst0::INSTR` 资源。 |
| LAN SCPI Socket | 在设备池的「添加设备与地址列表」选择 SIGLENT SPS5000X 系列，填写当前地址，默认端口 5025。地址列表默认使用 VISA Socket；指定本地网卡地址可走直接 TCP。显式配置也可用 `tcp://<设备地址>:5025`，结束符 LF。 |

USB、VXI-11 和 VISA Socket 复用项目已有的 64 位 VISA Runtime。安装材料、许可、哈希和环境检查以 [组件清单](../../../deployment/components.json) 中的 `rs-visa` 为准。直接 TCP 使用系统网络栈。设备可使用 DHCP 或已配置的静态地址，应用发现只读身份。

## 单位与限制

下表为独立模式下每通道的额定上限。可设范围从 0 开始，实验限值可进一步收紧。电压设定和电流限值分别校验，实际输出受负载和设备恒功率工作区约束，电压和电流的额定最大值不可视为能同时达到的工作点。

写设定前只读核对通道独立模式、List 状态和相应设定来源。开启整机输出前还检查所有物理通道的输出控制来源、设定来源及电压和电流限值。读回不明确或存在越界值时阻止开启。关闭整机输出仍可明确提交。输出读回表示整机开关状态，端子是否带电还取决于通道使能、延迟、保护及接线。

每次设置只发送一次，经 `*OPC?` 后读取对应设定或整机输出状态。超时或损坏读回报告执行结果未确认。采集使用手册定义的文本标量回包，坏数据不进入实时曲线或记录。
