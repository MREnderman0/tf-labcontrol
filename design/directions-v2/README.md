# TF-LabControl 第二组视觉方向

这一组不再只更换配色，而是改变设备管理的基本形状和信息组织方式：

1. `01-command-center.html`：指挥台
   - 用设备状态表和操作行替代大卡片。
   - 适合 6–20 台设备同时在线、批量连接、地址和槽位管理。
2. `02-workbench-canvas.html`：实验编排台
   - 用功能槽位节点和连接线表达设备关系。
   - 适合后续手动联合采集、实验配置预设和设备拓扑讨论。
3. `03-instrument-index.html`：仪器目录
   - 左侧类别索引，中间设备详情，右侧槽位和绑定状态。
   - 适合按设备类别管理、逐台查看和配置功能槽位。

请先选 `1 / 2 / 3`，也可以说“1 的设备表 + 2 的编排区”或“3 的目录结构 + 1 的状态密度”。
