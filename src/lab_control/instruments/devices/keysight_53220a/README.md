# Keysight / Agilent 53220A

注册标识 `keysight.53220a`；精确匹配 53220A，不把 53230A 或 531xx 兼容模式当作本型号。

## 能力与协议

依据 [53220-90001 用户指南，第四版，2023-04](https://www.keysight.com/us/en/assets/9018-03351/user-manuals/9018-03351.pdf) 第 3、4、5、7 章，以及 [Keysight 编程参考（经销商镜像）](https://www.transcat.ca/media/pdf/keysight-53220A-53230A-programmer-guide.pdf) 的 SENSe:FUNCtion、DATA:REMove、FORmat 和 INPut 章节。接入 CH1/CH2 的单通道频率测量，归入现有“频率计数器”工作区。CH3、周期、频率比、时间间隔及无间隙采样不在本包支持范围。

频率使用 Hz；正式采集使用 `FORM:DATA REAL,64`、`FORM:BORD NORM`，每帧一次 `INIT:IMM`，通过 `DATA:REM? 1,WAIT` 读取并移除一个定长 IEEE 488.2 二进制块。扫描、只读连接和备份不初始化格式、不触发测量。完整配置仅在首次开始或参数变化后准备；逐帧不使用 MEAS/CONF，不重复获取旧数据。

监测界面沿用 K+K 的布局，只提供通道选择、采集节奏、频率趋势、当前帧导出和连续记录，不显示设备参数配置区。闸门时间及输入参数沿用仪器当前值；软件采集间隔只控制读取节奏，不设置仪器闸门。下表保留型号协议与硬件维护入口的参数范围，不代表监测页提供编辑控件。

当前功能通过 `SENS:FUNC?` 核验；`FREQ` 表示默认 CH1，`FREQ 2` 表示 CH2。切换使用 `SENS:FUNC`，保留输入参数；初始化和其改变的数学处理/触发/格式设置随采集配置留存。`CONF?` 只是上次远程配置的历史，在上电后可能为空，不用于当前模式判断。

## 连接与驱动

LAN VXI-11 优先，VISA SOCKET 端口 5025 单独验证；均使用 PyVISA 与已登记的 `rs-visa` 组件。依赖来源、固定版本、检测和离线材料见[公共组件清单](../../../../../deployment/components.json)及[下载资源](../../../../../docs/generated/download-resources.md)。不新增 Python 包、SDK 或服务，不更改系统网络、代理或设备地址，不自动安装或重启。

要求原生 Windows 10/11 x64 环境、正式运行目录及公共硬件锁一致。资源、完整序列号、接口验证和默认连接以运行目录资产台账为准。LAN 需要同网段可达；DHCP 使用现有服务。具体现场固件可用性由逐台批次判断。

## 单位与限制

| 参数 | 单位 / 范围 | 关联约束 |
| --- | --- | --- |
| 闸门时间 | s，0.0001～1000 | 10 μs 步进；独立于软件刷新间隔 |
| 耦合 | AC / DC | AC 频率下限 10 Hz，DC 下限 1 mHz |
| 输入阻抗 | Ω，50 / 1000000 | 输入保护不自动清除；现场幅度未知时不测试信号通道阻抗切换 |
| 输入量程 | V，探头倍率 1 时 5 / 50，倍率 10 时 50 / 500 | 不自动改变探头倍率；缩小量程前校验手动电平 |
| 手动触发电平 | ±1.025 × 当前量程 | 步进为量程 / 2000；先关闭自动电平 |
| 自动电平 / 低通滤波 | 开 / 关 | 自动电平可能无绝对读回；滤波截止频率 100 kHz |
| 输入斜率 | POS / NEG | CH1/CH2 分别设置 |

每次测量只允许一路。通道在监测及二进制收尾期间锁定；数据读取使用有限超时，长闸门停止须等待在途读取结束。时间为主机读回时间，不声明硬件时间戳。帧必须通过块长度、字节序、点数、数值和前后配置验证；无效值、超时与截断不显示或保存。参数或采集命令失败不自动重发。

## 文件与公共依赖

协议、量程和 SCPI 命令分别由本包 `protocol.py`、`profile.py`、`adapter.py` 维护。型号测试、脱敏夹具位于 `tests/`；实机入口及离线摘要转换器位于 `hardware/`。共享 UI、会话锁、调度和存储使用公共实现，不交叉导入其他型号。

## 已知限制与待测

| 功能或问题 | 限制 / 原因 | 后续验证 |
| --- | --- | --- |
| 非频率初始模式 | 当前要求面板已处于普通频率模式，避免不可恢复的跨功能设置 | 单独扩展各功能状态与恢复契约 |

| 无输入 | 可能超时、无效值或噪声数值，不能作为有效信号证据 | 连接已知信号补测 |
