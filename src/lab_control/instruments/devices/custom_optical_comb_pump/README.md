# 光梳地检泵浦驱动（自制）

适配器 `custom.optical_comb_pump` 由操作员在设备总览点击「手动连接泵浦」并选择实际接线的 COM 口。连接先只读校验 CH 1 的六帧设置回复。库存记录人工选定的协议与资源，序列号留空。

## 能力与协议

依据用户提供的《泵浦激光驱动设备通信说明》，文档未注明版本。每帧 8 字节，结构为 `48`、命令码、4 字节大端数据、通道、`53`。扫描仅枚举串口资源。每次打开或故障后重连均须手动选口，一键连接排除该适配器。

| 入口 | 软件支持 | 协议依据 |
| --- | --- | --- |
| 设备管理 → 泵浦驱动 → 状态与诊断 | CH 1 电流设定值、LD 目标温度、输出状态、电流上限、热敏电阻 B 值、低通滤波状态 | §5.1 `0xF1`，校验六帧长度、顺序、命令码、通道及开关值 |
| 设备管理 → 泵浦驱动 → 常用 | 关闭 CH 1 泵浦输出，用户确认后执行一次 | §3.5 `0xF2` 数据 `0`，校验原帧应答，再用 `0xF1` 核实关闭状态 |
| 实时监测 → 泵浦驱动 | 按所选项目被动读取 CH 1 的标量，可单次读取、监测和记录 | §6.2 单项读取，查询数据字段填零，待实机核对 |

## 连接与驱动

Windows COM 口对应 VISA ASRL 资源，使用现有 PyVISA 与系统 VISA 运行库，串口固定 115200、8 数据位、无校验、1 停止位，关闭流控及文本终止符。既有组件 `rs-visa`、`serial-interface` 的来源与准备方法见[下载资源](../../../../../docs/generated/download-resources.md)。实际转接器型号、驱动和接线待现场核对。

## 单位与限制

- 设置电流与电流上限的 µA 转 A。目标温度按 §3.4 示例的千分之一摄氏度转 °C。
- 实测电流转 A，LD 电压转 V，光电二极管电流按 0.1 µA 转换，热敏电阻阻值用 Ω。LD 实测温度、TEC 电流和 TEC 电压显示四字节原始码。
- 回包短缺、帧格式不符或串口超时会结束当前通信，监测停止并提示重新选口。关断异常显示输出待核实，写入只发送一次。断开会话仅释放串口。

## 文件与公共依赖

`adapter.py` 维护命令、解码和操作边界，`transport.py` 维护串口配置。公用设备会话负责资源锁、审计和采集记录，协议样本与离线用例位于 `tests/`。
