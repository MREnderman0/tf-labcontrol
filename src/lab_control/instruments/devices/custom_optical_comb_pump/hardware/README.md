# 光梳地检泵浦驱动实机计划

## 目标与授权范围

逐项区分 Windows 枚举、人工接线核对、VISA 连接、CH 1 设置读取、标量读取、关断读回、重新选口和物理输出测量。关断试验须有现场明确授权。

## 前置条件与备份

记录人工资产号、实机接线、当次 COM 口、VISA 和串口转接器。使用正式程序持有设备锁。备份 `0xF1` 原始六帧及输出状态。实机测试以输出已安全关闭的状态开始。

## 测试矩阵

单口只读复核使用 `verify-readonly`。明确指定 `--adapter custom.optical_comb_pump`、`--resource` 为实际 COM 口、`--transport visa`、`--folder` 为运行目录下的 `hardware-tests/<人工资产号>/<批次>`。该入口检查枚举、连接、CH 1 设置及实测电流协议读回。

| 阶段 | 操作与证据 |
| --- | --- |
| 枚举 | 核对系统 COM 列表及所选接线 |
| 连接与只读 | 设备总览手动连接，记录 `0xF1` 与所选实时项的原始帧、单位和现场参考值 |
| 关断与测量 | 在许可工况发送一次关断，核对原帧应答、设置读回和独立物理测量 |
| 重新连接 | 断开后重新人工确认 COM 口，重新执行只读核验 |

## 停止与恢复

通信异常或输出状态不明时停止本轮，记录最后确认的值并由现场人员核对设备。实验结束核查关闭状态及备份中的其余设置，输出保持关闭。

## 交付与未测

在运行目录按人工资产号和批次保存原始 `results.json`、`summary.json` 和索引，遵循[实机记录规范](../../../../../../docs/testing/records.md)。当前没有实机批次。
