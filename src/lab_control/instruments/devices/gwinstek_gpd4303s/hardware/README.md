# GPD-4303S USB 空载控制计划

## 目标与授权

只访问单设备配置中明确指定的 GPD-4303S 和完整序列号，经 PyVISA ASRL 连接；四路端子空载，只接电源和 USB。控制测试须由用户明确授权低压输出开关及关闭输出时的跟踪模式切换。默认入口只读；程序不发现或访问其他设备。

```powershell
.venv-dev\Scripts\python.exe -m lab_control.instruments.devices.gwinstek_gpd4303s.hardware.validate_control --config '<运行目录内单设备配置>'
.venv-dev\Scripts\python.exe -m lab_control.instruments.devices.gwinstek_gpd4303s.hardware.validate_control --config '<运行目录内单设备配置>' --control-unloaded
```

可用 `--asset-name '<已有资产目录>'` 关联历史。程序检查正式运行目录及固定硬件锁的物理路径，拒绝重定向副本。占用时留档并停止，不杀进程或绕过锁。复用项目 `.venv-dev`、已安装 VISA/FTDI；依赖下载遵循[国内镜像及禁代理规范](../../../../../../docs/development-environment.md)。

## 备份与测试矩阵

通过身份校验后，读取四路 VSET/ISET/VOUT/IOUT、整机输出和跟踪状态，保存初始快照及 SHA-256。备份不完整不进入写入阶段。所有操作通过原设备 worker；该独立测试进程不启动监测或自动同步调度。

1. 输出关闭并核对，切独立模式；CH1～CH4 分别设置 1.0/1.5/2.0/2.5 V、0.100 A。每次写入读回并比较其他通道，容差 1 mV / 1 mA。
2. 输出关闭、CH3 电流 0.100 A 时依次验证 5.000/5.001/10.000 V，保存范围快照，随后恢复 2.000 V。越界组合仅在协议夹具中测试。
3. 输出关闭时验证串联、并联和独立模式的状态映射及参数联动；重新设置四路低压点。
4. 确认独立模式、低压和限流后，整机输出开启；等待约 1 秒，读取一轮后关闭并核对。仪器内部电压读回偏差 ≤0.05 V，空载电流绝对值 ≤0.02 A。不是外部测量精度验收。

## 停止与恢复

开始写入前先验证全部恢复目标均能通过后端校验。如果原值超出额定范围，停止测试并保留原值；只有用户明确指定合法收尾电流时才使用 `--final-ch4-current <A>`。原始备份不改，报告分别保存获准目标与原值差异。此参数不是范围绕过。

超时、身份冲突、异常读回或意外通道变化停止后续测试。不自动重放失败写入。通信退化后最多重新建立一次经过身份核验的会话，再读取实际状态；无法读取时不继续恢复写入。

恢复先关闭输出并确认，进入独立模式；按合法 CH3 组合顺序恢复四路原电压、电流，再恢复原跟踪模式，逐项比较。输出保持 OFF，不恢复原来的 ON。恢复失败停止后续步骤，保存最后有效观测和错误，最终状态无法确认时明确标为未知。

恢复成功后释放并重连，核对身份、参数和输出关闭，最后发送 LOCAL。LOCAL 无状态查询证明，面板控制恢复需人工核对，单独记录，不推断通过。禁止复位、保存/调用存储器、改波特率或固件。

## 留档与验收边界

用户要求前面板逐项确认时，使用包内 `validate_panel.verify_panel` 分两次会话：设定低压值并发送 LOCAL 后释放句柄，保留数值等待人工确认；确认后显式传入原批次路径恢复。不在后台定时恢复、不自动启动输出。每次连接在身份查询前发送 REMOTE；LOCAL 后通信超时仍立即结束该批次，不能把先前重连通过推广到此状态。

`validate_reconnect.verify_reconnect` 为明确选择的资产执行三轮同会话 LOCAL/REMOTE 及 LOCAL 后释放/重连；开始先读完整快照并确认输出关闭。记录器仅允许只读命令及 LOCAL/REMOTE，不允许电压、电流、跟踪或输出写入。每次比较身份、设置及输出，最终 LOCAL 后禁止额外仪器查询。失败中止，不循环重试。模式命令各等待 1 秒的策略由本型号传输层实现；本地模式下只能查询软件元数据，进入远程后再读取设备。

`reviewed_independent_panel_photo` 只接受执行者已经核对为独立模式且输出关闭的当次照片，复制到运行批次并记录哈希。原始未知状态不改写，面板证据作为单独的恢复目标来源；不能把任意照片或历史截图当成当前状态。恢复只接受成功设值并明确等待确认的源批次。V2.12 ASCII `00` 的已验证兼容差异见[型号说明](../README.md)；其他未知状态仍拒绝未经核对的数值写入。

每次运行保存 results.json、summary.json、通信字节/时间、初始备份与哈希、请求/回读、范围/模式快照和恢复差异；成功、失败、受阻都更新索引。通信仅留运行目录，源码夹具脱敏。

连接、参数控制、空载输出、恢复、重连分别判定；外部仪表测量、带载恒流/额定功率及串并联通电输出列未测。更新资产连接说明及[离线总览](../../../../../../docs/hardware-test-records.md)，保留旧批次。
