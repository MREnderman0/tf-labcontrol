# Tektronix AFG31252

注册标识：`tek.afg31252`。本目录是型号兼容实现、说明、脱敏测试样本及硬件验证入口的维护源；两个逻辑通道对应仪器 CH1/CH2。

## 能力与协议

`adapter.py` 定义型号能力与协议，`limits.py` 定义本型号关联范围。支持基础波形、频率、Vpp 幅度、偏置、相位、负载、脉冲、斜坡、扫频、AM/FM/PM、突发及编辑存储器上传/选择。静态能力给出总体范围；每次相关写入在同一会话 worker 内重新读取当前状态，检查有效交集，不自动钳位、改变单位或重发命令。

- 公共噪声名称 `NOIS` 写为 `PRNOISE`；仪器返回的 `PRN` 规范化为 `NOIS`。
- 基础相位使用 rad；正弦按 0.01°、其他适用标准波形按 0.1° 分辨率比较，保留实际读回。PM 对外使用 deg，写入显式 `DEG`，弧度查询结果转为度。
- 修改电压及相关参数前必须明确选择 VPP，按当前负载、频率、仪器高低电平限制和实验限值共同校验。不能将高阻端的 10 Vpp 上限用于 50 Ω 负载。
- 任意波形按大端无符号 16 位承载 0…16382 编码，上传到对应 EMEM1/EMEM2。上传与选择分开，不自动打开输出。编辑存储器完整备份后可原样恢复并比较字节。
- `FUNC?` 对编辑波形只返回通用 `EMEM`，不能从这个返回值推断存储器编号或实际输出波形。

依据：[编程手册 077148803](https://www.tek.com/-/media/documents/077148803_afg31000_series_programmersmanual_nov2020.pdf)、[规格手册 077148901](https://download.tek.com/manual/077148901_AFG31000_Spec_PV_Sept2019.pdf)、[数据表 75W-61444-3](https://download.tek.com/datasheet/AFG31000-Datasheet-EN-US-75W-61444-3.pdf)。

## 输入范围与组合校验

| 参数 | 本型号约束 |
| --- | --- |
| 连续频率 | SIN：1 μHz–250 MHz；SQU：1 μHz–160 MHz；RAMP：1 μHz–2.5 MHz；PULS：1 mHz–160 MHz，还须满足脉冲时序；EMEM：1 mHz–125 MHz。DC/噪声不接受周期频率设置 |
| 突发频率 | SIN 上限 125 MHz、EMEM 上限 62.5 MHz；其他支持波形继续检查各自边界，DC/噪声禁用突发 |
| 幅度 | 50 Ω：1 mVpp–5 Vpp，频率大于 200 MHz 时上限 4 Vpp；高阻：2 mVpp–10 Vpp，大于 200 MHz 时上限 8 Vpp。有限负载 R 使用 R/(R+50 Ω) 缩放高阻范围，再与 API 总体边界及实验限值取交集 |
| 偏置/电平 | 50 Ω：`abs(offset)+Vpp/2 ≤ 2.5 V`；高阻：≤5 V，DC 只检查偏置；同时满足 `VOLT:LIM:LOW/HIGH`，不修改仪器限幅 |
| 负载 | 设置接受 1–10000 Ω；高阻读回按手册的无限大标记识别。负载变更要求输出 OFF，并校验缩放后的电压与实验限值；硬件补测保持原负载 |
| 脉冲 | 脉宽 4 ns–999.99 s，并与周期、前后沿、HOLD 模式、占空比及突发延迟联动检查；宽度至少为前后沿之和的 0.625 倍，至多为周期减去该和的 0.8 倍。不能只按 160 MHz 名义上限放行 |
| 扫频 | 两端均满足当前波形范围；项目规定 start≤stop，按顺序更新；总扫描/保持/返回时间≤500 s。切换波形和启用扫频也检查端点、电压及模式冲突 |
| AM/FM/PM | 载波限定 SIN/SQU/RAMP/EMEM；内部调制频率要求 INT。FM 频偏同时受波形上限与载波两侧频率余量约束；活动 FM 下修改载波也检查。启用调制与扫频/突发互斥 |
| 通道与未知状态 | 频率/电压联动开启时拒绝独立相关控制；相位联动单独检查。活动 FSK/PWM、附加噪声/外部叠加、未知波形/状态或查询失败阻止对应写入 |

协议出处：077148901 第 2–5 页（波形频率、突发、幅度、偏置），077148803 的 `OUTPut:IMPedance`、`SOURce:FREQuency`、`SOURce:PULSe`（第 133 页脉宽关联关系）、`SOURce:VOLTage:LIMit` 和调制章节。4 ns 脉宽采用编程/规格手册的较严值；后续数据表写 3 ns，本适配未据此放宽。

继续保留 API 的保守限制：占空比 0.01–99.99%、扫频时间 1 ms–300 s、AM 深度 0–100%、内部调制频率 1 mHz–100 kHz、PM 0–180°、上传 32–131072 点。界面中的总体边界不等于每种工作状态都可用；不满足组合约束时提供拒绝原因。软件覆盖边界与故障注入，不能替代边界处的输出精度测量。

## 连接与驱动

复用可用的 Windows x64 VISA 与 USBTMC 驱动，通过 PyVISA 和项目会话连接。配置必须给出完整资源及预期序列号。型号支持的接口与现场可用接口分开记录。

USB 和 LAN VXI-11 共用同一型号适配器；LAN 身份与连接已有验证。默认接口及各接口控制覆盖以运行目录结构化资产状态为准，旧 LAN 失败作为历史证据保留。

## 文件与公共依赖

- `__init__.py`：唯一设备定义及文档元数据；`adapter.py`：型号协议；`limits.py`：型号范围与状态关联。
- `tests/`：专属单元测试、恢复/故障注入；`tests/fixtures/`：迁移前能力基线、脱敏协议样本。
- `hardware/readonly.py`：只读复核；`hardware/validate_usb.py`：输出关闭的完整控制测试；`hardware/validate_ranges.py`：合法边界设置与只读越界拦截补测。
- 仅依赖公共领域模型、SCPI 基类、传输/IEEE 块工具及通用硬件记录工具，不导入其他型号或旧信号源集合实现。
