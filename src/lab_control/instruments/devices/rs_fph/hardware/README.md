# FPH02 V1.40 LAN 验收

默认只读；仅访问配置中的一台 FPH02。控制矩阵要求 RF INPUT 无信号或接 50 Ω。固件保持 V1.40，不复位、不校准、不更改网络、不保存/调用仪器文件。不开展选件专项或物理精度测量。

## 入口

```powershell
python -m lab_control.instruments.devices.rs_fph.hardware.validate_control --config <单设备配置.toml>
python -m lab_control.instruments.devices.rs_fph.hardware.validate_control --config <单设备配置.toml> --control
python -m lab_control.instruments.devices.rs_fph.hardware.validate_control --config <单设备配置.toml> --restore-from <历史批次目录>
```

配置使用 `adapter="rs.fph"`、`transport="visa"`、完整 `expected_serial` 和当前 LAN 资源，建议 `timeout=10`。历史恢复核对完整身份、固件与快照哈希。恢复失败后不会自行再次写入；新恢复批次需要用户明确授权。

## 预检、备份与矩阵

核验正式运行目录、库存和锁的最终 Windows 物理路径，拒绝重定向副本。遵守全局及设备锁；不终止 GUI/其他进程。先在锁内只读核验身份并合并 DHCP 新地址，再交给一个会话 worker。不得把 IP 当资产身份。

备份本轮会修改或影响的频率、RBW/VBW 及自动状态、电平、衰减、扫描/计数、触发、检测器、轨迹、标记、显示范围、格式和字节序。关闭标记的坐标不查询；其他活动标记、非标准应用、补偿偏移、前放等超出可靠恢复路径时停止相关参数测试。换能器补偿状态查询在 V1.40 超时，排除该专项，不冒充已经备份。

| 分组 | 范围 |
| --- | --- |
| 频率 | 中心 100/110 MHz，跨度 1/2 MHz，起止 99–101 MHz；关联读回 |
| 带宽 | RBW 10/30 kHz、VBW 3/10 kHz；自动/手动 |
| 电平 | dBm 下 −20/−10 dBm，衰减 20/30 dB及自动状态 |
| 扫描 | 单次完成、连续启停；零跨度手动 0.1/0.2 s，确认自动状态关闭；V1.40 不支持零跨度自动扫描时间 |
| 检测/标记 | POS/SAMP及自动状态；标记 1 启停、指定频率、峰值范围 |
| 数据 | 普通/零跨度，ASCII/REAL32 各不少于20帧；冻结同一条曲线对比编码精度 |
| 稳定性 | 连续纯监测60秒；逐项恢复并释放/重连3次 |

每帧检查完整回包、711点、有限数值（含 SCPI 不可用数值哨兵）、单位、坐标和配置来源。格式比较只改变编码；不将扫描噪声变化当精度结论。单次只在立即触发和完成时限可满足时启动；外部触发不做专项验证。

## 停止、恢复与留档

超时、截断、部分执行或读回不一致立即停止后续测试，不重发写入、不自动换协议或降级 ASCII。先读取实际状态，再停止扫描，恢复单位、频率、手动值、自动状态、检测/轨迹/标记、格式与触发，最后恢复连续状态；首次恢复失败立即停止，记录最后确认状态。

会话因错误进入保护状态、无法读回时，首次恢复流程最多建立一次新的同资源连接，并重新核对完整身份；不重放失败命令。恢复本身失败后，必须另行获准才能进入新的恢复批次。离屏原始标记通过硬件入口专用操作恢复，要求其他标记关闭、普通频率坐标及硬件范围合法；公共控制仍限定在当前曲线范围内。

恢复比较逐字段保留实际差异；自动状态与派生读回均核对。恢复设置不等于恢复历史曲线。测试前替换单帧导出与分段记录工厂，完整数组仅在内存中校验，通信和报告仅存长度、点数、轴、单位、时序、配置及哈希，并检查没有新曲线文件。

所有批次保存 `results.json`、`summary.json`、`initial_snapshot.json`、`restoration-differences.json`、`communication.jsonl` 和 `record.md`，调用公共文档维护器更新索引与资产状态。失败和受阻同样留档；未知资料不能标为通过。

## 软件验证与边界

专属 Mock 覆盖解析、离散范围/关联零写入、禁用标记的安全读取、完整/缓存上下文、首帧与失效、超时不重发、截断/错误点数、单位/零跨度、格式初始化失败和恢复首次失败即停。公共会话、监测、逐帧记录、显示帧导出和 Qt 页面另做跨层回归。源码样本脱敏，真实证据仅保存在正式运行目录。
