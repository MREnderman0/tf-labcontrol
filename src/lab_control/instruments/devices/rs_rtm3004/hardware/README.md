# R&S RTM3004 硬件计划

## 目标与授权范围

只访问用户明确选定、具有可信序列号的 RTM3004。默认 LAN PyVISA VXI-11；本入口的可写阶段只适用于用户确认四个模拟输入均未接信号的测试。使用者必须已有参数修改和启动采集的授权；文档本身不授权操作。

## 前置条件与备份

按 [实机留档](../../../../../../docs/testing/records.md) 核对正式运行目录、全局/资产/主机锁及当前有效 DHCP 租约。型号、序列号、固件、网络地址、手册副本和通信保存在运行目录。

以 configure_acquisition=False 连接，保存四通道、水平、触发、采集、自动长度、传输格式、字节序和运行状态。错误队列在首个写入前有界读取并保存，不使用 *CLS。备份不完整则不执行测试写入。

## 测试矩阵

| 阶段 | 方法和预期 | 验证边界 |
| --- | --- | --- |
| readonly | 只读身份、全部状态、范围及重连 | 不初始化采集，不把连接通过写成整机验收 |
| controls | 四通道开关、档位、偏移、耦合、探头倍率、带宽、触发电平；水平位置、时基、触发源/边沿、平均及高分辨率往返 | 每组比较相关配置；拒绝不匹配读回，测试点在当前范围内 |
| coordinates | 中心参考点下，分别设置正负水平位置并读取波形 | 时间轴中心与显示位置的差不超过两采样间隔；测试后恢复 |
| acquisition | 显式 REAL32/LSBF 初始化，开启四通道，AUTO/Stop，冻结读取、连续监测和记录参数锁 | 首帧前替换单帧导出和分段记录工厂，只保存元数据；核查无曲线文件 |
| recording | 同一公共采集流程，真实有界记录和停止收尾 | 二进制提交数一致、CSV 转换完成；离线逐样本核对另存独立证据 |
| Auto | 单独入口保存 SYST:SET 完整块及触发耦合/迟滞/滤波/保持、Zoom、数学/参考曲线、发生器输出；重复只读备份稳定后执行 | 两种监测状态各执行一次 AUT，30 秒有界完成，更新参数/范围并读取至少三帧有效波形；记录锁、元数据工厂及排空检查 |
| 空通道 / 刷新 | [refresh.py](refresh.py) 的 verify_refresh 使用单资产配置与独立批次目录；先备份，按当前状态检验空通道，再显式 Run 读取至少六帧并比较逐通道哈希，Stop 后核对两帧冻结内容 | 仅用于已授权且无外接信号场景；元数据记录、禁止曲线文件、恢复控制及重连。初始无空通道时该分项保持 not_tested，不人为清空波形历史 |
| 稳定记录快照 | 同一刷新入口通过 timebase 参数在备份后临时选择稳定窗口，核验首帧 full、后续 cached，比较原参数读回时间、逐帧数据哈希及查询数量；结束恢复原时基 | 只缓存本批设置，波形数据每帧读取；显式单帧保持 full，修改或异常后重建。另在原慢时基验证增长与扫描回卷的完整校验，不缩减型号范围 |
| restoration / reconnection | 读实际状态，按已确认原值恢复，关闭重连再核验 | 探头先于档位/偏移，时基先于水平位置；恢复格式、自动长度及运行/停止语义 |
| physical_output | 已知信号源、参考仪器、负载和容差另行明确 | 当前无外接信号，not_tested |

入口：

```powershell
.venv-dev\Scripts\python.exe -m lab_control.instruments.devices.rs_rtm3004.hardware.verify --config <仅含本资产的配置.toml> --phase readonly
```

经本次任务授权的可写阶段为 controls、coordinates、acquisition、recording。配置必须只有一台 rs.rtm3004 且包含 expected_serial；每次建立独立批次。程序不扫描其他资产。

Auto 使用独立入口，默认只读；已有 Auto 测试授权且四路输入均无外接信号时才加 `--execute`：

```powershell
.venv-dev\Scripts\python.exe -m lab_control.instruments.devices.rs_rtm3004.hardware.autoset --config <仅含本资产的配置.toml> --execute
```

Auto 测试恢复只回写一次原始设置块，独立恢复 FORM/FORM:BORD，并核对全部已查询控制、输出状态和设置块字节；停止语义必要时显式恢复，重连仍跳过初始化。完整块不同即保留恢复失败，不忽略未知字段，也不自动重放。01.400 首次测试的设置块差异未全部解释；已查询控制及格式在独立恢复批次读回通过，后续复测与其本批备份逐字节一致，不追改首次结论。

## 停止与恢复

任一测试失败停止后续测试写入，保存完整异常。恢复前重新读取状态；通信不可用时不盲写、不复位、不重放、不绕过会话错误或占用锁。已开始的恢复失败不会自动执行第二遍。显式恢复需另建批次、引用原备份、重新核对身份，并记录最终可确认状态。

采样率与自动选出的实际记录长度是观测值，仍完整保存；恢复比较自动长度开关，不强制把旧波形长度当作配置写回。停止后的 COMP/BRE 不等于恢复旧波形内容。Auto 会删除注释、关闭菜单和数学/参考曲线；旧波形历史、菜单不作为可恢复内容。内部发生器只读核验输出，绝不发送输出开关命令；校准和出厂复位均不在本测试范围内。

## 交付与未测

每次成功、失败、中止均生成 results.json、summary.json、record.md 并调用公共台账维护器更新索引。当前固件的存储深度写入未通过，软件禁用该写操作。触发电平离散档位读回不一致保持拒绝。Auto 已开放，空输入仅验证控制与采集流程；已知信号自动选档效果、单次/普通触发性能、高级触发、全内存/分段、USB 和物理精度仍未验收。
