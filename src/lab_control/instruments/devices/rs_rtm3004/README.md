## 能力与协议

四通道模拟示波器，复用正式示波器工作区、分类卡片和深色琥珀主题。通道开关、垂直档位/偏移、耦合、探头倍率、20 MHz 带宽限制、时基/水平位置、模拟边沿触发、平均和高分辨率控制集中在本包。

Auto 按钮调用原生 `AUToscale`（`AUT`），只发送一次，以最多 30 秒的完成查询确认，再读取实际通道、水平、触发参数及关联范围。仅恢复操作前正在运行的软件监测，用户中途停止优先；记录及二进制收尾期间锁定 Auto。完整回包仍在变化时由公共监测最多等待 30 秒，无效帧不显示或保存；拒绝、超时和通信错误分别处理，不重发设置。

操作布局沿用 DHO924 的共享工作区：通道卡片、水平/触发设置、微调和 Auto，不额外增加 RTM 专用按钮行。运行/停止在触发设置中选择 AUTO/NORM/STOP；“开始/暂停监测”控制软件读取，保持原仪器状态。首帧完整核验，稳定监测/记录沿用本批参数快照，始终重新读取每通道的 REAL32 数据，绝不缓存波形样本。

数据处理沿用 DHO924 的离线流程：在单设备或批量采集历史中选择记录，点击“处理数据”，按原始时间线查看各通道波形，并自动逐帧、逐通道生成 PNG。本型号保存的物理量为 voltage，单位 V，时间轴为 s；包含 scope_display 元数据的记录支持“示波器刻度”与原始电压视图切换，光标及图片始终使用物理值。旧记录缺少显示元数据时使用原始坐标。只读取已保存数据，不连接仪器；缓存帧保留原参数读回时间。详见[历史采集与数据处理](../../../../../docs/guides/data-processing.md)。

依据 [厂家用户手册](https://scdn.rohde-schwarz.com/ur/pws/dl_downloads/pdm/cl_manuals/user_manual/1335_9090_01/RTM3000_UserManual_en_12.pdf)，1335.9090 revision 12，§17.4 控制及 §17.9.1 波形导出。固件 01.400 的冻结同帧 REAL32 与 ASCII 已逐点比对；包内夹具为脱敏软件样本，不冒充原始实机记录。

## 连接与驱动

默认 PyVISA，已验证 LAN VXI-11。USB VISA 尚未实测。复用既有 `rs-visa` 组件和项目环境，没有新增依赖或安装材料；见 [部署组件](../../../../../deployment/components.json)。

使用当前 DHCP 租约定位，再核对完整型号与序列号。库存保存经身份核验的 MAC 关联，租约地址不是静态部署要求。扫描和 `configure_acquisition=False` 连接不修改数据格式；正常采集连接显式设置 `FORM REAL,32` / `FORM:BORD LSBF`，保存设置前值并逐项读回。连接不会启动采集，关闭软件连接也不会自动恢复传输格式或改变运行状态。

## 单位与限制

| 项目 | 实现和校验 |
| --- | --- |
| 垂直/水平/触发范围 | 在当前通道查询 MIN/MAX；写入前重新查询关联范围。范围查询失败禁用写入，不使用另一通道的范围 |
| 设置完成 | 写入一次、完成查询、实际读回和错误队列；读回不一致按拒绝处理，不扩大容差掩盖离散档位 |
| Auto 的仪器行为 | 原生 Auto 会改变水平/垂直/触发设置、关闭数学和参考曲线、删除注释并关闭菜单；不会把无信号选档结果当作精度验收 |
| 输入耦合 | DCL：直流 1 MΩ；ACL：交流 1 MΩ；DC：直流 50 Ω；GND：虚拟接地。耦合与端接含义按本型号手册解释 |
| 存储深度 | 显示当前实际长度及采样率。01.400 的写入读回未通过，当前禁止修改；自动长度设置在测试后恢复 |
| 二进制数据 | IEEE 488.2 定长块，REAL32 小端，数值已经是 V；不再次乘探头倍率。长度必须等于头部点数 × 4 |
| 时间轴 | 独立读取 XOR/XINC，并与头部起止时间及点数核对；只接受有限值、正间隔、单值样本，最多 4,000,000 点/通道 |
| 运行中窗口增长 | 二进制接收上限为型号硬上限 16 MB，不用稍早的点数截断完整回包。仅当运行中、前后起点一致、独立 XINC 不变、两次头部终点均符合时间栅格、块内点数位于前后头部点数之间，接受实际块对应的增长窗口；保存两次头部与增长标记。增长窗口不建立稳定帧缓存 |
| 扫描重新开始 | 仅在完整配置核验路径，前后独立 XOR/XINC 完全一致、两次头部均符合时间栅格、块内点数恰好等于其中一个头部时，接受该头部对应的完整记录，标记 sweep_rollover。其余回卷、坐标变化仍丢帧等待，坏数据仍报解析错误；不在一次请求内重读波形 |
| 空通道与冻结波形 | 固件 01.400 的完整 `0E+00,0E+00,0,0` 表示尚无已采集波形，暂停读取并提示，保持连接且不保存空帧。触发模式显式控制仪器；停止时可读取已有冻结波形，界面明确标示 |
| 一致性 | 首帧/显式 full 前后完整配置校验；稳定帧标为 cached，保留原参数时间。每帧核对独立坐标、数据头、数据块、传输格式和运行状态；配置变化与通信/解析错误分别上报，无效帧不显示或保存 |
| 快照依赖与失效 | 快照覆盖全部通道档位/偏移/位置/探头/耦合/极性/带宽、水平窗口、触发及采集配置。模式、上下文或通道集合变化，Auto、任何设置、主动刷新、异常及重连使缓存失效；与快照不同的采样间隔或超出两采样间隔的水平原点变化也丢帧重建。参数修改后保守完整核验，不套用 DHO 的型号局部依赖 |
| 显示 | 使用仪器报告的水平格数（本机 12 格）；垂直参考值为 offset − position × scale。未验证方向的拖动不做偏移预览 |
| 采集/记录 | 被动读取现有导出窗口，不切换 DEF/MAX/DMAX，不启动采集；显式 Run/Stop 控制采集。各通道顺序读取，不声称跨通道来自同一次触发 |
| 保存 | 共用有界逐帧记录、二进制收尾和 CSV 转换；记录期间锁定参数，停止后不等 CSV 完成才释放仪器 |

<a id="8-限制和故障处理"></a>
## 已知限制与待测

| 功能或问题 | 限制 / 原因 | 后续验证 |
| --- | --- | --- |
| 存储深度设置 | 本机写入后的 ACQ:POIN? 仍为当前记录长度，未确认目标值生效；UI 只读 | 区分配置目标和已采集长度，验证运行/停止及自动长度组合后再开放 |
| 触发电平离散档位 | 可能出现请求 3 mV、读回 4 mV；拒绝不一致，不自动重发 | 厂家确认分辨率及关联量化规则后增加显式适配 |
| Auto 自动选档效果 / 单次 / 普通触发 | Auto 已开放且空输入流程通过；已知信号下选档效果以及 SING、NORM 触发性能未验收 | 接参考信号单独测试 |
| Auto 测试完整备份 | 01.400 加载 SYST:SET 不恢复 FORM/BORD，须独立恢复；首次批次设置块还有未解释差异，保持未完全核验。修正后的独立复测设置块与本批原备份逐字节一致 | 不把后续通过覆盖首次结论；未公开设置块字段不猜测其含义 |
| 全内存 / 分段 / 历史 / 数字通道 | 当前只读现有模拟通道导出窗口；分段操作需选件，逐段时间戳未实现 | 分别实现并验证 |
| 峰值 / 包络 | 双值样本当前拒绝；设置能力不代表相应波形导出已支持 | 扩展配对样本格式及一致性检查 |
| 停止状态与历史 | 测试后恢复运行/停止语义；COMP 与 BRE 都是停止状态。重新采集替换的波形历史不恢复 | 不把控制恢复描述为历史数据恢复 |
| 错误与恢复 | 失败批次保留；会话异常后不绕过锁或自动重连重放写入，另建有依据的恢复批次 | 以每批最终读回为准 |
| 前面板改动 | 波形头不包含完整垂直/探头/触发配置，稳定帧无法自动识别这些外部修改；缓存字段保留旧读回时间，不冒充当前读回 | 纯监测时主动“刷新参数”；记录时先停止记录再改。软件设置和 Auto 自动使快照失效 |
