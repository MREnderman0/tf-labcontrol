# Siglent SDG6032X-E 硬件计划

## 目标与授权范围

按单设备配置中的完整型号、预期序列号及 LAN INSTR 资源执行。只读入口只查询与重连；控制入口必须显式 `--write`，验证双通道基本正弦参数。文档不自动授权测试，执行以本次用户授权为准。遵守[记录规范](../../../../../../docs/testing/records.md)。

## 前置条件与备份

核对正式库存、运行目录及全局锁的物理路径。两路须为 SINE、输出 OFF、高阻或 50 Ω，且跟踪/耦合、调制、扫频、突发关闭。不自动关闭现有输出或改变模式来满足前提；前提不符则受阻留档。

首个写入前保存双通道 OUTP/BSWV/MDWV/SWWV/BTWV、COUP、MODE、ROSC 和身份原始快照及 SHA256。备份不完整则不写。每次测试值须不同于原值；保存完整 plan.json、原始通信及逐项请求/读回。测试不涉及波形存储器或文件。

## 停止与恢复

超时、解析错误、隔离失败或读回不符立即停止后续测试写入。失败会话须显式关闭并重连，读取真实现态后只恢复当前未恢复参数一次；已尝试的恢复命令不自动重放。再次失败则记录最终状态未知或差异，不能宣称恢复成功。不恢复出厂、不写输出、不清错误队列，不终止其他进程或绕过锁。

## 交付与未测

每批保留 results.json、record.md、summary.json、communication.jsonl、初态及计划，结束后调用公共 refresh_after_batch 更新资产说明、index.md 与 overview。只读入口不覆盖控制证据。未测项目包括物理性能、输出开关、波形切换、高级模式、USB/SOCKET 及其他固件；补测另建批次，保留原证据。
