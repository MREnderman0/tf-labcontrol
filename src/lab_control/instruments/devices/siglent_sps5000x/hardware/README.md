# SPS5000X 实机测试计划

按 [实机留档规范](../../../../../../docs/testing/records.md) 先核对铭牌、完整型号、序列号、固件和当前接线，选择一个明确的资源。USB-TMC、VXI-11 和 TCP 5025 各建独立批次。使用正式运行目录与硬件占用锁。

## 只读入口

从仓库根目录运行。将占位符替换为本次授权的单一资产，USB-TMC 或 VXI-11 选择 `visa`，Socket 选择 `tcp`。

```powershell
.venv-dev/Scripts/python.exe -m lab_control.instruments.devices.siglent_sps5000x.hardware.readonly --model SPS5081X --serial '<序列号>' --resource 'tcp://<当前设备地址>:5025' --transport tcp
```

入口按完整型号和序列号核验身份，查询电压、电流限值和整机输出开关，比较初始与重连快照。批次保存在运行目录 `hardware-tests/<完整型号>-<序列号>/<时间批次>`，含原始结果、通信、快照及摘要。出现资源占用、驱动缺失、查询失败或读回变化时保留阶段状态。开关读回只用于软件状态核对。

## 控制与物理输出

仅在已有写入和输出授权、接线及负载核验完成后执行控制测试。

1. 记录每通道的原始电压、电流限值、通道使能、控制来源、模式、保护和整机输出。先确认独立模式、普通直流和内部设定，再核对安全限值。存在不可读状态则停止写入。
2. 在输出关闭且端子已核验无电时，选择安全的小幅设定，逐项读取并与请求比较，记录分辨率、命令完成和读回。逐通道验证其余通道的设定与使能。
3. 输出测试由现场人员明确确认后执行。使用合适量程的参考仪表和负载，分别记录开关读回、各通道实际电压电流、输出延迟及端子放电结果。
4. 中途超时或结果不确定时停止后续写入，保留通信和状态。按原始快照和已授权恢复顺序先处理输出，再恢复设定，逐项读回并记录最终端子状态。只有取得对应证据的阶段才能标为通过。
