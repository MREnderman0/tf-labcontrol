# Ceyear 6362D 光谱分析仪

独立适配标识 `ceyear.6362d`，类别 `optical_spectrometer`，通道 1 对应主轨迹 TRA。本包是型号协议、范围、文档、测试及硬件入口的唯一维护源。

## 能力与协议

依据厂家 [6362 系列程控手册 B.11（2025-08）](https://www.ceyear.com/optical_spectrum_test-163?act=97&type=file)，适用软件 **2.1.0 及以上**。完整型号接受 6362D，以及现场身份回包并由用户核对铭牌的 CY6362D；保留原始型号，不将 6362C 或其他系列当成别名。身份须包含可信序列号。

| 能力 | 当前契约 |
| --- | --- |
| 波长 | 起止、中心、跨度，波长单位 nm；写入前验证关联端点 |
| 分辨率 | 离散 RBW：0.02、0.05、0.1、0.2、0.5、1、2 nm |
| 灵敏度 | NORMAL、MID、HIGH1、HIGH2、HIGH3；首轮实测限 NORMAL/MID |
| 采样点 | 101～50001，整数；自动点数必须显式关闭后才能写手动点数 |
| 扫描 | 单次、重复、停止；单次完成使用厂家状态查询，有会话超时上限 |
| 数据 | TRA 的完整 X/Y 曲线及实际点数；ASCII、已验证版本 REAL64；显示 nm/dBm；REAL32 仅有解析器，生产采集未启用 |

只查询已有曲线不会启动扫描。单次采集是显式动作，不发送未经列明的 `*OPC?`、`*CLS` 或错误队列查询。`CONDITION=1` 在重复扫描中也会出现，不能据此认定停止。

## 连接与驱动

优先 PyVISA：`TCPIP0::<仪器地址>::10001::SOCKET`，端口 **10001** 依据程控手册第 5 页。手册通用示例中的 5025 不作为本型号端口。使用现有 `rs-visa` 组件及其离线维护材料，无新增 Python 依赖、SDK、服务或驱动；组件来源与部署约束见项目根目录 `deployment/components.json`。

扫描、只读预检和备份必须传入 `configure_acquisition=False`，不改变传输格式。正式采集连接要求该软件版本已有冻结曲线 ASCII/REAL64 的逐点比对记录，才初始化为 REAL64 并读回核对。**2.2.1 已实测为小端 REAL64**，正式默认初始化和读取已复核；其他版本明确阻断，不能通过尝试两种字节序或静默切换 ASCII 绕过。鉴定时的离线双字节序比较仅位于硬件验证包内。格式初始化的尝试与读回进入公共会话审计。普通断开不自动恢复格式；硬件验证入口显式恢复其备份值。

B.11 第 14、16 页明确说明 **只支持静态 IP，不支持 DHCP、DNS/域名访问**，掩码为 255.255.255.0。现场前面板没有 DHCP 开关，与手册一致。不要把内部 Windows 的通用能力当成该仪器支持 DHCP；扫描本身不改网络。

Socket 必须先认证：`open "用户名"`，收到 `AUTHENTICATE CRAM-MD5` 后发送密码行，确认 `ready` 后才查询身份。2.2.1 实机挑战末尾带句点，本包明确兼容这个回包；拒绝其他挑战、认证失败或超时，不自动重试。只读认证会进入远控，断开后回到本地；不初始化测量格式。

已保存且验证过的主地址通过公共 `remembered_lan` 参与日常扫描，本包提供只读认证及身份回调，扫描无需创建采集会话或改变格式。重启软件后仍须本轮认证与真实身份核验成功才显示在线；新身份不会继承原资产设置。前提是电脑实验网口与仪器静态地址同网段、LAN 发现开启且凭据已配置。首次广播未找到时仍需明确 IP，普通扫描不添加网卡地址。

按用户要求，凭据明文保存在项目 `.local/device-auth/ceyear_6362d/`，按资源区分，`.local/` 排除 Git 与发行包；安装版使用运行目录 `config/device-auth/ceyear_6362d/`。可运行 `python -m lab_control.instruments.devices.ceyear_6362d.authentication --resource <VISA资源>` 录入。通信留档不保存密码，密码不进入连接配置、库存或诊断查询名称。

## 范围与约束

| 项目 | 条件 |
| --- | --- |
| 波长 | 600～1700 nm，起始小于终止；中心±跨度/2 必须在范围内 |
| 跨度 | 首版保守接受至少 0.001 nm；零跨度/时间轴未实现 |
| 单位 | SCPI 波长查询为 m，明确换算到 nm；首版采集要求波长横轴和 dBm 纵轴 |
| 比较精度 | 测试矩阵波长量绝对容差 0.000001 nm，仅用于回包舍入；离散设置、枚举、点数、布尔精确比较，不代表物理准确度 |
| AUTO 扫描 | ABORT 不能可靠停止，拒绝相关控制；先由面板恢复到可判定状态 |
| 标记限定范围 | 开启时拒绝波长控制；不隐式关闭 |
| 主轨迹 | 启动扫描要求 TRA 为 WRITE；其他轨迹仅在硬件备份中读取，不提供控制入口 |

每帧在轨迹前后读取配置与实际点数。完整但配置变化的帧报 `configuration_changed`；截断、非有限数、空轨迹、越界/非递增波长分别报明确错误，不发布无效帧。读取全部仪器点数，不把请求点数当成实测点数。采用公共 `MeasurementBatch`、监测调度、逐帧记录与有界队列，不增加公共型号分支。

固定轨迹可能保留历史扫描的轴，与当前波长设置不同；以曲线 X 回包为准。元数据明确轨迹状态和配置来自当前仪器，不能把当前设置当成历史扫描配置，也不能把读取时间当成完成新扫描的时间。

## 已知限制与扩展

其他轨迹控制、频率横轴、W/密度单位、内置光源、校准和专项分析未实现。**6362D-H04 是 GPIB、外部触发输入/输出接口选件**，并非 LAN 的前提；未确认选件时不发送其触发查询或写入。仅凭模式查询不能确认原重复扫描正在运行。

完整恢复原运行状态的默认测试入口要求额外面板状态依据。用户明确允许放弃恢复原扫描运行状态时，可使用硬件入口的 `--leave-stopped`：保留触发设置，备份参数与七条轨迹，临时将 TRA 设为 WRITE、其他 WRITE 轨迹设为 FIX，测试后恢复参数、轨迹属性与活动轨迹并保持停止；不声称恢复历史曲线。仅接受可完整读回的 WRITE/FIX 轨迹，不重建平均或计算状态。单次扫描有完成期限，失败后先发送 ABORT 再做普通查询，避免被待触发扫描阻塞；后续测试写入立即停止。

实机通过后在本包更新资格表、测试与当前状态，并重新生成文档。仅经 `devices/catalog.py` 注册；移除注册及本包不删除用户配置、资产或历史记录，旧配置显示适配器不可用。
