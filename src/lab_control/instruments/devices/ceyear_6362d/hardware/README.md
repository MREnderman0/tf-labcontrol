# 6362D 实机验证计划

## 接口与授权

只读入口：`python -m lab_control.instruments.devices.ceyear_6362d.hardware.readonly --config <单设备TOML>`。

冻结格式验证：`python -m lab_control.instruments.devices.ceyear_6362d.hardware.validate_control --config <单设备TOML> --qualify-transfer --x-atol-nm <依据ASCII回包固定的容差> --y-atol-db <固定容差>`。此模式要求 TRA 为 FIX，仅允许传输格式写入；不会切换轨迹属性、活动轨迹、扫描或测量参数。恢复原格式并核对全部设置，再释放重连三次。

完整控制：同入口使用 `--control --original-scan stopped|repeat --trigger absent|off` 及比较容差；必须已有相应现场状态证据。不能用猜测的选项绕过前提。两种写入模式互斥。

若用户明确授权测试后保持停止、不恢复原扫描运行状态，使用 `--control --leave-stopped` 及比较容差，原扫描和 H04 状态可保持 unknown。此策略记录用户授权的恢复边界，保留触发设置；不将未知选件当成存在，也不发送选件专属查询。新扫描超时后先 ABORT，停止后续测试写入，再恢复已备份参数。

只访问当次明确选定的 LAN 地址、10001 端口，优先 PyVISA。先核对正式库存、配置、全局锁和设备锁的最终物理路径；AppData 重定向或锁占用则留档受阻，不使用另一个目录绕过。只读连接显式关闭采集初始化。网络维护需独立于扫描；不更改光输入、校准或内置光源。

厂家依据为包内 README 所列 B.11；软件低于 2.1.0 或版本不明时停止写入。记录完整厂家、6362D 型号、可信序列号、软件版本及来源哈希。正式批次在任何仪器 I/O 前创建，初次身份未知使用 `6362D-pending-identity`，确认后按完整序列号维护资产。

## 备份与阻断条件

备份波长起止/中心/跨度、RBW、灵敏度、采样点/自动状态、横纵单位、传输格式、TRA 属性、当前轨迹、介质和波长/功率偏移、标记限定范围、扫描模式及状态。H04 触发仅在已确认选件时查询。保存原有轨迹原始回包、格式、点数、哈希；明确曲线备份与恢复设置不同。

需要可信的面板运行状态和触发信息。AUTO 扫描、非普通波长/dBm、TRA 非 WRITE、标记限定扫描、原设置无法验证恢复、其他活动轨迹不能可靠备份等情况均阻断测试写入。不得用 `CONDITION=1` 推断重复扫描已经停止。

上述面板状态与 TRA WRITE 前提可由明确授权的 `--leave-stopped` 策略替代：只接受七条轨迹均为 WRITE/FIX，备份后临时启用 TRA、固定其他 WRITE 轨迹，最终恢复属性及活动轨迹。AUTO、不可恢复的参数或轨迹状态仍受阻。H04 触发状态不变；因此扫描可能等待外部触发，此时只记录超时和实际恢复结果。

## 参数矩阵与采集

| 分组 | 目标 | 读回及关联检查 |
| --- | --- | --- |
| 波长 | 1540～1560 nm，中心 1550 nm，跨度 20 nm | 起止/中心/跨度关系；每项绝对容差 0.000001 nm |
| 分辨率 | 0.1、0.2 nm | 离散值及关联点数/自动状态 |
| 采样 | 自动状态、1001、2001 点 | 精确点数；写手动值前显式关闭自动状态 |
| 灵敏度 | NORMAL、MID | 枚举精确比较及扫描配置 |
| 扫描 | 单次、重复、停止 | 单次轮询 `:STATUS:OPERATION:CONDITION?`；有上限等待 |

上述精度固定于 `state.py`，仅容纳测试值数值转换的舍入，不以放宽容差掩盖设备量化。实机若给出不同量化需要停止、补充依据并另开批次。

先验证已有曲线，再单次采集。冻结同一轨迹并按 ASCII 精度预先固定比较容差，比较 REAL64 的块长度、点数、字节序、波长和功率；前后 ASCII 也必须相同。证据不唯一就阻断，运行时不尝试字节序。合格后才将准确版本加入资格表。

至少 20 帧有效曲线、60 秒连续监测、停止排空和 3 次释放重连。首帧前替换导出与分段记录工厂为仅保存元数据，监测首帧前启用逐帧记录并在排空后核对记录数等于有效帧数，核查无新增曲线文件。备份曲线单独放在批次中，不属于性能记录输出。曲线读取次数不代表仪器完成了同样数量的新扫描。新扫描须核对完成状态，以及读回的 1540～1560 nm、2001 点新曲线。

## 异常与恢复

超时、解析错误或读回不一致立即停止后续测试写入，不重放不确定命令。仅执行有备份依据的恢复：停止；关闭自动点数；按端点依赖恢复波长；恢复分辨率、灵敏度、手动点数及自动状态；恢复格式；恢复扫描模式。核对全部只读/可写快照后，最后恢复已确认的重复运行状态。恢复第一处失败即停止并记录最终状态未知；不能把重新启动命令已发送当成面板运行状态确认。
