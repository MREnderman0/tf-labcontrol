# 芯明天 E00 / XMT 串口兼容层

注册标识为 `coremorrow.xmt`。这是一个独立的协议兼容包，依据芯明天官方 E00 资料、厂家软件 25.09.26 的串口 DLL 头文件以及 COM6 原始帧建立。它不把 USB 桥的 VID/PID、桥序列号或回包占位字节当成设备型号/序列号；协议身份仍保持“芯明天 XMT 兼容控制器”，现场铭牌为 `E00.C3-13`。

串口回包仍未提供可核验的仪器序列号和固件号，因而 UI 和台账会显示“协议身份、型号待核”，不会伪造精确身份。

## 能力与协议

已验证帧格式为 `AA address total_length B3 B4 payload XOR`。长度包含整帧，末字节为前面所有字节的逐字节 XOR。当前包实现：

- `voltage`：通道电压设置，`B3=0, B4=0`，通道号为 0 起始；电压编码为符号/整数/万分位小数。按 E00.C3-13 的功率模块资料，兼容层开放正向控制范围 `0.0～120.0 V`；负压输出仍不开放。每次写入前保存读回值，写入后显式读回核验。
- `measured_voltage`：`B3=51, B4=0` 三通道回读，解析为伏特；读回失败或偏差超过 0.01 V 时写入结果为不确定/拒绝，绝不自动重发。

- `power_config`：`B3=80, B4=0`，解析通道数、传感器类型、带宽代码及 DA/AD 分辨率，并保留完整脱敏原始 payload。
- `raw_channel_data`：默认 `B3=5, B4=0`，按通道返回原始 4 字节值；字节缩放和物理单位仍待厂家按完整型号确认。

| 波形能力 | 实现与边界 |
| --- | --- |
| `standard_waveform` | 单次发送 `B3=15, B4=0`，通道、波形、峰峰值、频率、偏移一帧提交，无确认回包，不重发 |
| 波形类型 | 正弦波 `Z`、方波 `F`、三角波 `S`、锯齿波 `J`；官方上位机选择分支核实，不能发送下拉框序号 |
| 数值编码 | 峰峰值和偏移沿用非负电压编码；频率为 2 字节整数 Hz 和 2 字节万分位，均大端；离线替换官方 DLL 的 WriteArr 捕获，不打开设备 |
| 频率范围 | `0.0001～10000 Hz`：下限由编码分辨率确定，上限来自官方 E00/E01 的 E18 输出波形频率规格；不从放大器带宽代码推断。实机本轮只发送 1/2 Hz，整个范围的物理性能未测 |
| 电压范围 | 峰峰值必须为正，偏移是中心电压，原始与编码后的 `偏移 ± 峰峰值/2` 均须在 `0～120 V` 内；越界拒绝，不截断 |
| `waveform_stop` | `B3=17, B4=0` 加单通道编号，只停止该路；无独立运行状态确认 |
| `normal_mode` | 停止可能活动的通道，再逐路恢复波形启动前保存的直流值并有界读回；失败保留快照及不确定状态 |
| `control_state` | 当前协议未找到可靠的模式、波形运行与四项参数读回接口；这些字段为未知，软件命令记录另列来源。B3=54 是启停速度配置，不能当运行状态 |

输出开关、闭环模式、校准、相位、频率递增和带单位连续采集仍不开放。`channels=<n>`（1～8）和 `data_command=5|6` 可在现场配置中显式选择；当前实测资产为 3 通道。

## 设备管理双模式

顶部切换常规／标准波形，两页均为三路纵向卡片。常规目标输入独立保存，不随实际电压漂移；步进以输入为基准。标准波形包含四项参数及发送、停止；首次草稿为正弦波、1 Hz、0.2 Vpp、偏移 0.1 V。

打开、重连时优先采用可靠仪器状态；当前协议无此读回，恢复该资产的上次模式和草稿，并标明“当前未确认”。目标、方向、步长和波形草稿按资产/通道保存在现有工作区数据库；命令结果、执行前检查点与直流恢复快照由型号包单独保存。读回或写入成功不会清除独立目标输入。

首次连接或重连后，运行状态未知会暂停自动电压轮询和常规写入；用户可明确点击“停止波形并进入常规”，然后设定电压或发送波形。打开页面、切到标准波形页、重启及重连均不发送输出命令，也不修改仪器上电设置。发送过波形后切回常规会停止并恢复原直流值；没有快照时只停止，提示用户明确设定电压。正常断开仅收尾本会话实际启动的波形；异常连接保留未恢复证据，重连不会自动执行旧命令。

波形活动期间旧电压标为历史值；“命令已发送”不代表仪器确认运行或物理输出通过。普通电源的页面与监测规则不变。

## 连接与依赖

支持 `transport=serial` 的 COM 端口和 `transport=visa` 的 `ASRL...::INSTR`。串口使用 8N1、无流控、无终止符，波特率由配置指定；COM6 在 9600 和 115200 下均得到相同配置帧。运行时只依赖项目已有的 pyserial/PyVISA 和 `serial-interface` 组件；32 位厂家 DLL 仅作为现场证据，不加载进项目 x64 进程，也不随源码分发。

启动后的第一次扫描会自动枚举串口。对已验证的 USB 桥 VID/PID `0483:0002`，发现服务会用 `coremorrow.xmt` 发送一次只读配置帧；协议核验成功后，COM 号会作为当前连接资源进入“电源”设备池并可直接连接。该步骤不写设置、不把 USB 桥序列号当成仪器序列号；其他未验证的串口仍显示为待绑定资源。若设备在程序启动后才插入，点击“扫描设备”即可重新执行同一流程。

## 测试与限制

型号专属测试：

```powershell
.venv-dev\Scripts\python.exe -m pytest src/lab_control/instruments/devices/coremorrow_xmt/tests -q
.venv-dev\Scripts\python.exe -m pytest tests/integration/test_coremorrow_e00_ui.py tests/integration/test_coremorrow_waveform_ui.py -q
```

实机入口必须显式指定一个串口和人工资产目录；只读入口为 `hardware/readonly.py`，标准波形入口为 `hardware/validate_waveform.py`。当前覆盖如下，完整原始结果、真实地址、资产标识和批次索引保存在运行目录。

| 验证项目 | 当前结论 |
| --- | --- |
| 枚举、协议连接、配置和通道读回 | 已完成；协议不能报告完整仪器型号、序列号和固件，精确身份仍待核对 |
| 四类波形与参数调整 | 三路均发送过 1 Hz / 0.2 Vpp / 0.1 V 偏移，并小幅调整至 2 Hz、0.4 Vpp / 0.3 V 偏移；波形目标上沿不超过 0.5 V |
| 多路启动、单路停止 | 已验证所发送帧与通道隔离寻址；实际输出是否停止及其他路物理隔离未测 |
| 切回常规和恢复 | 已保存启动前的三路直流读回，恢复后独立读回偏差在 0.01 V 内；不是将所有通道强制清零 |
| 断开和重连 | 已完成；新连接只查询，不重放输出；当前波形状态保持未知 |
| 物理波形、频率和幅度 | 未连接外部测量仪器，均为未测；不构成整机验收 |

设备配置帧没有返回额定上下限；本包采用官方 E03.00.13 的 `-20～+120 V` 输出资料中的 `0～120 V` 正向控制子范围。全范围物理性能、精确身份及外部输出测量仍待补充。
