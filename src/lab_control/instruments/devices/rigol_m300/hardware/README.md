# M300 实机测试计划

## 范围与前置条件

仅访问显式指定的 `rigol.m300` VISA 资源与完整预期序列号，核对正式运行目录、硬件进程锁及资源/身份租约。只读入口查询身份、模块和状态；正式温度测试使用 RES 实测电阻及显式传感器曲线。默认不停止其他进程或面板启动的扫描来绕过空闲预检。用户另行明确授权停止并切换时，记录授权范围、原始设置、停止读回及读数内存备份；逐项切换和读回，明确保留的最终状态。一次维护授权不改变正式连接的保护规则，也不得绕过其他进程持有的锁。

## 入口

```powershell
# 只读身份、模块和状态；不运行 READ? 或写参数
.venv-dev\Scripts\python.exe -m lab_control.instruments.devices.rigol_m300.hardware.readonly --resource '<VISA资源>' --expected-serial '<完整序列号>'
```

原 `hardware.verify` 和 `validate_control` 控制入口转发到下述电阻换温登记入口；旧 `--nominal`、内置温度及 C/F 仪器切换测试已移除。历史原始结果和格式转换器保留。温度专用协议查询仍用于备份仪器原状态，不构成直接温度采集路径。

## 备份与步骤

### 保存连接配置

只有用户确认接线及后续自动恢复范围后才登记。配置绑定完整型号、序列号、固件及输入/DMM 模块，地址和接口不是曲线匹配依据。新电脑需要在其正式运行目录重新登记或迁移经核验的资产配置；配置缺失或旧版本不会回退到仪器内置温度。

```powershell
# 示例映射须与实际传感器相符：前 16 路 MF501，后 3 路使用用户提供的 Excel 曲线
.venv-dev\Scripts\python.exe -m lab_control.instruments.devices.rigol_m300.hardware.connection_setup --resource '<当前VISA资源>' --expected-serial '<完整序列号>' --group 401:416=mf501-v1 --group 417:419=4813-s02-v1 --duration 10
# 停用自动配置，保留仪器设置及原有日志；TEMP 直读仍被禁止
.venv-dev\Scripts\python.exe -m lab_control.instruments.devices.rigol_m300.hardware.connection_setup --resource '<当前VISA资源>' --expected-serial '<完整序列号>' --disable
```

`--home` 必须指向已核验的正式运行目录，不可换目录绕过占用。曲线 ID/版本和系数随源码分发，不依赖用户下载目录；相同标称阻值不代表相同曲线。范围重叠、跨槽、无效通道、未知曲线或旧标称阻值输入会在通信前拒绝。

1. 核验精确身份，以 `configure_acquisition=False` 连接，保存原资产配置、所有已识别输入、扫描和全局设置。
2. 保存授权的逐通道曲线映射。正式重连检查 IMM、次数 1、DMM 开启、监视关闭、附加读数字段关闭、继电器打开及扫描范围。活动扫描导致预检受阻时不写参数、不发 READ?，保留连接及已登记曲线；界面提示具体待调整项，硬件验收仍记为 blocked，不把连接成功当成采集通过。
3. 空闲预检通过后，仅切换所选输入到 RES 及恢复扫描列表，不改量程、触发或未选输入。每次写入前持久化日志，逐项读回核实；正确配置不重写。不确定写入不自动重放。
4. 在首帧前备份已有读数；READ? 会覆盖仪器读数内存，原值仅能留档，不能宣称恢复。
5. 使用正式公共监测和记录流水线运行指定 1～60 s，逐帧核对温度、实测电阻元数据、曲线及完整通道集合。停止并核对收到、提交、转换和文件实际帧数及参数解锁；记录每路实时峰峰值。后续离线处理使用完整记录末尾 30 min。
6. 重连核对正确配置零重写，再采集一帧并比较最终设置；成功后保留用户授权的电阻换温方案，关闭软件监测及会话。失败记录最后核验状态，不自动补偿或重放写入。

## 记录与未测项目

每次测试，包括失败、受阻，保存独立 `results.json`、`summary.json`、`record.md`、原始通信、初始/最终快照及记录目录，更新公共台账。原始失败批次不修改，后续补测另建批次。真实地址、序列号和实测数据只留在运行目录。

公式实现、参考样本和窗口边界可通过离线软件测试核对；公式正确不代表传感器准确度已验收。未使用参考温度计或标准电阻时明确列为未测。USB、未接输入、其他模块和外部连续扫描兼容性各自验收，不以只读连接替代完整采集验证。
